SalesAnchor

営業の流れを整理する

営業の問題と、
SalesAnchorによる解決。

複数の受信箱、在庫確認、帳票作成、受注後の管理。分断されたB2B営業を、一つの流れにつなぎます。

Problem→Solution→Result

5つの問題と解決

確認と手入力を、
次の仕事へ渡せる情報に変える。

各行を左から右へ読むだけで、現場の問題、SalesAnchorが担うこと、その後の変化が分かります。

メッセージ対応

実装確認済み
Problem

複数のメッセージツールを、スタッフが個別に確認している。

→
Solution

Meta・DiscordのメッセージをSalesAnchorの受信箱に集約する。

→
Result

顧客との会話と対応履歴を、一つの画面で確認できる。

在庫確認

提供状況を個別確認
Problem

問い合わせのたびにLINEを開き、在庫を目視で確認・記録している。

→
Solution

WeGoの在庫情報をSalesAnchorへ同期する。

→
Result

LINEグループを探さず、アプリ内で在庫を確認できる。

見積書・請求書

一部実装
Problem

顧客、商品、状態、数量、価格を毎回手入力している。

→
Solution

登録済みの顧客情報と在庫情報を、見積書・請求書へ反映する。

→
Result

同じ情報の転記を減らし、帳票と顧客・在庫の整合を取りやすくする。

受注後の管理

一部実装
Problem

入金、仕入れ、発送状況を、注文ごとに個別確認している。

→
Solution

受注後の状況を、注文単位・段階別に表示する。

→
Result

現在の状況と次に行う作業を、チームで共有できる。

顧客管理

実装確認済み
Problem

顧客の属性や発注傾向が、担当者の記憶や個別管理に残っている。

→
Solution

顧客カルテに、会話履歴・顧客情報・取引情報をまとめる。

→
Result

担当変更時の引き継ぎや、継続的なフォローに活用できる。
