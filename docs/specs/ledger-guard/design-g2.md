# design G2 — 本店main以外警告（差分設計）

## 変更点（1箇所・scripts/new-worktree.sh）
- 引数チェックの手前（WITH_CLAUDE 代入の直後）に警告ブロックを追加:
  実行場所が ~/worktrees/ 配下でない（＝本店から実行）かつ、現在ブランチが
  main でない場合、「本店が main 以外に居る」警告と復帰コマンドを表示する。
  **止めない**（exit しない）——救出系の正当作業を塞がないため。
- テスト容易性: ブランチ名は G2_TEST_BRANCH 環境変数で注入可能
  （未設定時は実ブランチ）。引数なし実行は使い方表示で即終了するため、
  警告表示の実測が副作用ゼロで行える。

## 変えないもの
机作りの全既存挙動（reaper・上限・登録・worktree作成）。警告は表示のみ。

## KGI-G2の判定（実測3件）
（G2.1改修 2026-07-04: 測定対象を実行場所から本店そのものへ変更。git-common-dirで
本店を特定するため、worktree内から実行しても本店を監視できる＝worktree内で黙る
盲点を解消。PO指摘起点。警告文の絵文字は輸送時の写し崩れ対策でWARNING表記へ）
T1: 本店から G2_TEST_BRANCH=release/foo 注入 → 警告=1件
T4: worktree内から同注入 → 警告=1件（旧設計では0＝盲点解消の実証）
T2: G2_TEST_BRANCH=main・引数なし実行 → 警告表示=0件
T3: 本店(main)・注入なし・引数なし実行 → 警告表示=0件（実ブランチ経路の確認）

## 先に言う弊害
警告のみで強制力はない（強制は第1弾のcommitガードが担当。役割分担）。
