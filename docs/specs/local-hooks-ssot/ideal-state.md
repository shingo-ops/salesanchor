# 個人側検問の正本化 あるべき姿(PO自筆・情景のまま)

> この文書は何か(専門用語なしの1行):
> 個人側の検問がどうなっていてほしいかを、POの言葉のまま書き留めた正本。

親へのリンク: [README.md](README.md)

## あるべき姿

- パソコン個人側の検問5本が「何を・なぜ止めるのか」がリポジトリの中に正本として書いてあり、誰でも読める
- 検問の中身の変更はPRとGOで管理され、勝手に変わらない・黙って古くならない
- 検問が不合格を出したのに作業が素通りできてしまう穴がない
- 検問が止めた記録が残り、後から「いつ・何を・なぜ止めたか」を追える
- 新しいパソコンや新しい実装者でも、同じ検問を同じ設定で再現できる
