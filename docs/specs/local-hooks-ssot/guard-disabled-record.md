| # | 実測事実 |

## 3. CIへの影響（実測）

`scripts/check-hooks.sh`（60行）はフックスクリプトの**実行権限のみ**を検査する。
`.github/workflows/hook-permission-check.yml` は `scripts/check-hooks.sh` の変更時に発火する
paths フィルタを持つ。

PR #3172（HEAD `7b2fcead`）のCI 25件に、チェック名へ `hooks` を含むものは0件だった。

結論: `exit 0` の挿入は実行権限を変えないため、本無効化はCIに検知されず、影響しない。
