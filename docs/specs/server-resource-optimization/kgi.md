# KGI(○×で測る・数値化)

親: [README.md](./README.md)

軸1: いま片付ける
| # | 合格条件 | 測り方 | 合格ライン |
|---|---|---|---|
| K1 | 秘密含有.bak = 0件 | 対象VPSで実測 | 0件 |
| K2 | 未参照image・停止コンテナ = 0件 | docker実測 | 0件 |

軸2: 二度と静かには溜めない
| # | 合格条件 | 測り方 | 合格ライン |
|---|---|---|---|
| K4 | 監査ログ等の自動退避が登録あり＋実行成功、かつ止まったら気づく仕掛けがある | 登録実測＋避難訓練(止めて通知着信) | 在る=1 |
| K5 | ゴミ発生源すべてに自動掃除の仕掛けあり | 発生源一覧と突合 | 満数 |
| K6 | 各自動掃除に守り手が名指しで記録 | design.md維持の仕組み欄 | 空欄0 |
| K7 | prod1の空きメモリ ≧ 全体の20% | free実測 | 20%以上(現状2GB中空き103MB=約5%。増強とセットで達成) |
| K8 | 両VPSのディスク使用率 ≦ 60% | df実測 | 60%以下(現状 prod1=42% / prod2=9%) |

KPI: 達成KGI数 ◯/8。
※K9(早期警告)は別セッション対応済みのため本テーマから除外。K4はその既存警告に相乗りする。
