# あるべき姿(PO自筆・情景のまま)

親: [README.md](./README.md)

> サーバーのサーバーリソース最適化を実現したい
> サーバーのメモリとディスクのゴミや不要な占領するものは排除して今後たまらない構造に最適化する

PO補足(対話で確定した意図):
- 自動化優先。POは知識前提を持たず「なるべく自動で回る仕組み」を望む。手作業の掃除は前提にしない。
- 「二度と起きない」の正確な意味 = 二度と"静かには"起きない(満杯前に必ず声が上がる)。絶対保証は約束しない、で合意済み。
- ②型・③箱の削除は「不要というエビデンスが確立できれば実行、できなければ別の確実な方法」がPO条件。
- 必要分はサーバー拡張(増強)で確保する。不要なゴミを溜めて膨らむ構造は回避する(2026-07-20 合意)。
