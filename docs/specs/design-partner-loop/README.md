## 3. 確定した設計判断（2026-07-01〜02 の合意）
1. 3段階振り分け: 新規テーマ＝フルセット一式／既存の延長・修正＝新規作成せず既存の子ども履歴・進捗表に追記／軽微（1行修正等）＝台帳1行＋PRのみ。一律フルセットは形骸化するため採らない。
2. 1テーマ1フォルダ: 一式は物理的に同じフォルダに集約（リンク＋同居の二重防御）。型見本は docs/specs/doc-parent-child ＋ docs/handoff/doc-parent-child。
3. 正本の木: STANDARD-WORKFLOW.md を唯一の根とし、design-partner.md・ADR・エージェント定義・索引は参照でぶら下がる。矛盾時は根が優先。
4. 順序は蛇口→床: まず「今後分散しない仕組み」を作る。既存約30個の正本宣言には触れない。棚卸しは後の別便。
5. ADRは廃止しない: ADR＝「なぜその判断か」の記録。あるべき姿→KGI（願いと測定）とは分離・共存。
6. recon と design はモード分離（診断と治療方針を混ぜない）。
7. 設計パートナーの門番義務: 着手前に必ず索引で過去仕様を確認し、新規／延長／軽微を判定（design-partner.md KGI⑪）。
