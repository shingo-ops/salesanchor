# WhatsApp — 右上のメニュー（︙）

> この文書は何か（専門用語なしの1行）: 画面右上の「︙」を押して出るメニューを撮って、項目の並びと間隔を数字にした記録。項目は何も選んでいない。

親: [README.md](README.md) / 手順書: [../../../../handoff/app-visual-language/phone-capture-runbook.md](../../../../handoff/app-visual-language/phone-capture-runbook.md)

- 記録日: 2026-10-11 / 端末: 画面 1080x2340px・密度480dpi（3倍）。**px ÷ 3 = dp**
- **開き方**: 右上の `menuitem_overflow`（120x144px = 40x48dp）をタップ。
- **閉じ方**: 戻る（`keyevent 4`）。**項目は1つも選んでいない**（手順書 §0-4「メニューを開いて、何も選ばずに閉じる」）。
- メニューが開いている間、`mCurrentFocus` は `PopupWindow` になりアプリ名が出ない。前面の確認は `mFocusedApp` で行った（両方とも `com.whatsapp` であることを撮影の前後で確認）。

## 取得に使ったコマンド

```bash
adb shell input tap 1020 195                 # 右上の︙
adb shell dumpsys window | grep mFocusedApp  # 前面の確認（ポップアップ時）
adb exec-out screencap -p > <名前>.png
adb shell uiautomator dump /sdcard/d.xml && adb pull /sdcard/d.xml
adb shell input keyevent 4                   # 何も選ばずに閉じる
```

## 設計の要点（両方に共通）

- メニューは**画面右上から下へ伸びるパネル**で、文字は左揃え。アイコンは付いていない。
- 項目の縦の間隔は**144px = 48dp で一定**。文字枠の高さは65px（約22dp）で、残りが上下の余白。
- 文字枠の幅は492px（164dp）で、項目の文字数に関係なく一定。最後の項目だけ幅が異なる場合がある（会話側の「詳細」は396px）。
- 一覧側は6項目、会話側は8項目。**どちらも1画面に収まる数**に抑えられており、入れ子のサブメニューは無い。

## 押していない項目（記録）

一覧側の「すべて既読にする」、会話側の「ブロック」「報告」「消えるメッセージ」など、状態を変える項目は**一切押していない**（手順書 §0-5）。
