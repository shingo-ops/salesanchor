統一感のあるフロントエンドのUI/UXを実現したい。ページが複数ありそれぞれ機能は違うが、
同じ機能をもたせることが多い。表示形式やテキスト、アイコン、プルダウン、検索欄など
複数個所で使うパーツは、デザインシステム・デザイントークン・
シングル・ソース・オブ・トゥルースの定義に沿った管理ができる設計にしたい。
プルダウンの仕様を変更したら1部分だけで他のページには反映されない、みたいな
メンテナンスがしづらいUI/UXにはしたくない。
