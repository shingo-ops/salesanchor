## あるべき姿（PO決定・2026-07-21）

入力部品（プルダウン・ボタン・入力欄）の寸法を金型化する。高さと幅をそれぞれ3段階（sm/md/lg）の金型として用意し、各項目が高さと幅を独立に選べるようにする。同じ高さ・幅の金型を選べば全ページで完璧に揃い、操作台に載せたときフィルタとボタンが1行で水平に並ぶ。バラバラな寸法を、選べる金型に統一する。

記録: 高さ3段（h-sm/h-md/h-lg）× 幅3段（w-sm/w-md/w-lg）を独立の2軸として選択する（3×3=9通り）。操作台（ContentToolbar・page-header-v2 §2.5）の中身がこの金型に従うことで、フィルタとボタンの水平が崩れなくなる。手本の起点=リード（顧客管理>リード）の操作台。
