| # | 合格条件 | 測り方 | 合格ライン |
|---|---|---|---|
| ① | 全ページの階層地図が存在する | 地図のページ数＝ルート定義の実数（検算一致・漏れ0） | 一致 |
| ② | 子ページの題名は単体ページ名のみ（階層の併記なし） | ヘッダー題名に親名・パンくず様の併記があるページ数 | 0 |

| ⑧ | ヘッダー内のボタンは金型部品のみ | ヘッダー内の生button・手書きstyleボタン数（現状: 生button多数・recon.md §2） | 0 |
| ④ | ヘッダー枠中身の規格表が在る | design.md に規格表（在る=1/無い=0） | 1 |
| ⑤ | 規格外ヘッダーが残っていない | 全数調査で規格違反と判定されたページ数（検算つき） | 0 |
| ⑥ | 位置ズレを防ぐ番人が機械で守る | 外枠padding禁止＋規格検査の関所がCIに在り、違反サンプルで赤を実測 | 1 |
