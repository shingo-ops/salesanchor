「サイドメニューに表示されているページからサブメニューで子ページになっていたり、ボタンから設定をしたりする全てのページをページと解釈している。子どもはパンくずリストのように表示してほしくてこれらをどのページも一括で統合したい」

「スケジュールページだけヘッダーのタイトルの位置も若干右下になっているので全てのページで位置を統一させる仕組みを実現したい」

「タイトルサブタイトルの統一化が完了したので同じ要領でヘッダーの構成を統一する」

## 改訂（2026-07-19・PO決定）

初版の「子どもはパンくずリストのように表示してほしい」は、次のとおり変更する（出所: 設計セッション 2026-07-19・PO決定）:

「パンくずは廃止する。子ページもそのページ単体のページ名表記のみとする。戻る手段は戻るボタン1種類に統一する。階層の表示はサブメニューが担う。」

変更理由の記録: 階層表示の役目はサブメニューが既に果たしており、二重表示を作らないことが「同じ事実は1か所」の哲学に合うため。親が複数あるページ（二重居住・recon.md §4-1）の親決め問題も、この決定により解消する。

## 改訂2（2026-07-19・PO決定）

改訂1の「戻る手段は戻るボタン1種類に統一する」は、次のとおり上書きする（出所: 設計セッション 2026-07-19・PO決定）:

「戻るボタンはヘッダーから追い出す。ヘッダーは『題名・説明文・そのページの操作ボタン』だけとする。戻るはブラウザの戻る・サイドメニュー・サブメニューに任せ、戻るボタン自体を全ページから撤去する。」

記録: ヘッダーの定義＝題名・説明文・そのページの操作ボタンのみ。ナビゲーション部品はヘッダーの住人としない。
