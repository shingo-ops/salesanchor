# ページタイトル金型 KGI（○×で測る）

> この文書は何か（専門用語なしの1行）:
> ページ題名の金型化が完成したかを、誰でも○×で判定できる条件にした一覧。

親: [README.md](README.md)

| # | 合格条件 | 測り方 | 合格ライン |
|---|---|---|---|
| ① | 共通部品（金型）が存在する | 金型（PageLayout.tsx）が main に在る=1/無い=0 | 1 |
| ② | 字体・大きさ・色・配置の定義が金型1箇所に集約 | ページ題名の見た目CSS定義が金型指定ファイル以外に0件（grep実測） | 0件 |
| ③ | 全対象ページが金型を使う | ページ題名の生h1/h2残存数（design.md §対象外を除く） | 0件 |
| ④ | 1箇所直せば全ページ変わる | ②=0件で自動成立 | 成立 |
| ⑤ | 再発しない | 生h1/h2直書きの検出関所 or 人手ルール明記が在る=1/無い=0 | 1 |

KPI: 達成KGI数 ◯/5。
注: ③の「対象」はページ題名のみ。ナビ枠外画面（登録/ログイン/OAuth）・sr-only・ページ内の節見出しは design.md §4 の線引きにより対象外。
