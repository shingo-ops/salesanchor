## 境界（他テーマとの取り決め）

- ダッシュボード: 日々の行動提案・目標カスケードが役割。本テーマは売上実績の分析に専念。
- 顧客管理（CRM。未着手）: 顧客の理解・信頼構築が役割。本テーマは顧客名を軸にした集計は持つが、顧客の性質・コミュニケーション履歴等の理解機能は持たない。
- 受注管理（order-management）: Orderのステータス別業務操作が役割。本テーマはOrderの金額・分析結果の確認に専念し、ステータス変更等の業務操作は行わない。
- 取引フロー（transaction-flow）: Orderのデータ構造の正本。本テーマはそこから分析用に集計・表示する。

- ideal-state.md はPOの言葉のみで構成し、Planner・Generatorは書き換えない。
