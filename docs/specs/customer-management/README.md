
# 顧客管理（customer-management）— 設計仕様書（表紙）

> この文書は何か（専門用語なしの1行）:
> 顧客の情報がパッと見れて分析も出来て、誰が見てもその顧客の特性が理解できる顧客管理ツールの完成イメージ（PO自筆）とKGIを収めた正本。

- あるべき姿（POの言葉のみ・正本）: [ideal-state.md](./ideal-state.md)
- KGIと運用: [kgi.md](./kgi.md)
- 理想の設計図（To-Be）: [to-be.md](./to-be.md)
- 親: 索引 [docs/specs/README.md](../README.md)
- ステータス: あるべき姿・KGI・理想設計図（To-Be）確定（PO自筆・2026-07-10）。recon以降は未着手。

## 境界（他テーマとの取り決め）

- ダッシュボード: 顧客関連の数字を軽く（サマリー的に）表示してよいが、本格的な数値の正本（ベース）は本テーマ側が持つ（KGI C7）。
- 売上管理（sales-management）: 実績数字（Order単位）の分析が役割。本テーマは実績数字を含みつつ、顧客の性質・優先度・引き継ぎ情報の理解に専念する。
- 受信箱（inbox）: 顧客詳細ページから受信箱へジャンプする導線を持つ（顧客とのやり取りの実体は受信箱側）。
- 見積もり・請求書（quote-invoice）: 支払先情報・配送先情報は、請求書発行画面でプルダウン選択される元データ。本テーマの顧客詳細ページはこれを確認できる場所として機能する（複数件対応）。

- ideal-state.md はPOの言葉のみで構成し、Planner・Generatorは書き換えない。
