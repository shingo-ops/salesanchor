
# あるべき姿（PO自筆・原文のまま・2026-07-10）

本文はPO（しんご）の言葉が正本である。Planner・Generatorは書き換えない。

## 原文

顧客の情報がパッと見れて分析も出来て新人でも引き継ぎの人間でも誰が見てもその顧客の特性が理解できる顧客管理ツール

作りは売上管理と似ているが顧客別に特化した仕組みにしたい、顧客の分析をメインに、顧客名、販売方法(実店舗・ECサイト・ライブストリーミング)、取扱商材(ポケモン、ワンピースなど)、トータル受注額、1回あたりの金額、取引回数、取引期間、直近受注日付をメインページに表示しつつ、クリックすると下層ページでその顧客の詳細を表示
