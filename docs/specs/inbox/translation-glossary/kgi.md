## 運用方針（PO承認済み 2026-07-05）
- 辞書は2層: 共通ベース辞書（全テナント共有）＋テナント専用辞書（完全分離）。照合は専用→共通の順（専用優先）。
- 共通辞書はテナント全体で育てる。仕分けの既定は専用辞書（漏れ防止はオプトイン共有で担保）。共有時は語のみ運び、出所情報（テナント・顧客・会話）は運ばない。
- 段階導入: 初期＝テナント提案＋運営承認。テナント増加後＝複数テナント一致で自動昇格（仮）→再修正なしN回通過で確定→再修正多発で自動降格。運営の人手は衝突裁定のみ。
- 用語カードは「正式日本語・正式英語・日本語別名リスト・英語別名リスト」を持ち、翻訳前に別名を正式語へ言い直す（正規化→翻訳の2段構え）。
- 状態用語は文字列対応でなく属性の組み合わせ（封あり/なし×損傷あり/なし）に紐づける。

## 設計送り事項（design.md で詰める）
1. 自動昇格の閾値設計（一致とみなすテナント数・確定までの通過回数N・調整履歴の置き場）。
2. ニュアンス品質の運用指標化（再修正率の低下を track-record で追う）。KGIには入れない（○×一義判定不能のため）。
3. 言い回し学習（テナント別トーン見本）の分離（孫テーマまたは第2期）。
4. 運営承認画面の設計（提案語＋既存辞書との衝突有無の並記、承認SLA）。
5. ADR-110 2資料（sa-translation-subsystem／karte-reference-alignment）との整合は recon で実測してから設計。
