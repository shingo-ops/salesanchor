## 本テーマの範囲（境界）

- 本テーマ（親）が決めるのは「子テーマたちを受信箱画面上にどう配置して見せるか」だけ。
- 各機能の詳細仕様（翻訳の中身・Botの挙動など）は子テーマで定義する（下記一覧）。
- 操作性・見た目の質（速さ・LINE並みの操作感・3列の畳み方など）は本テーマの対象外。アプリ全体のフロント定義（別テーマ・関連: docs/specs/component-standard.md）が担当する。
- 手動記録の記録漏れ・記録遅れの担保（リマインド・未記録検知など）は本テーマの対象外。Bot・定型文の子テーマ、または分析AI検討再開時に扱う。
