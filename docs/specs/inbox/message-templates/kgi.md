# KGI(PO承認済み 2026-07-19・○×で測る・抽象語禁止)

> この文書は何か(専門用語なしの1行):
> 定型文が「できた」と言える条件を、画面で○×判定できる形で並べた合格基準。

親(あるべき姿+KGI)へのリンク: [定型文 README](README.md)

| # | 合格条件 | 測り方 | 合格ライン |
|---|---|---|---|
| ① | テンプレート設定画面で追加・編集・削除ができる | 1件のテンプレで追加→編集→削除の3操作を画面で実測 | ◯/3 |
| ② | 受信箱にテンプレ呼び出しのアイコンボタンが在る | 受信箱の会話画面でアイコンの有無を実測 | 1/0 |
| ③ | テンプレートがシーンごとに振り分けて選択できる | シーン2つ以上を作り、シーン別に一覧が切り替わることを実測 | 1/0 |
| ④ | 選択前に「どこに何が入っているか」が画面で分かる | 一覧に「シーン名・テンプレ名・本文の冒頭(プレビュー)」の3点が表示されることを実測 | ◯/3 |
| ⑤ | テンプレートを選択すると受信箱の入力欄に本文が記載される | テンプレ1件を選択し入力欄への転記を実測 | 1/0 |
| ⑥ | 送信は通常の送信ボタンから行われる(テンプレ専用の送信経路を作らない) | 転記後に通常の送信ボタンで送信され、会話に通常メッセージとして並ぶことを実測 | 1/0 |

KPI: 達成KGI数 ◯/6。

## 設計送り事項(design.md で詰める)
1. 入力欄転記後の書き換え自由(テンプレは下書き投入のみ・送信は通常手打ちと同一扱い)の設計保証。
2. 二層データ(デフォルト+テナント上書き)の持ち方。
3. 英語本文+和訳の持ち方・送信者への和訳表示(invoice-form-send のフォーム系送付との接続)。
4. テンプレ増加時の一覧の見せ方(④のプレビュー表示が縦に長くなる弊害への対処)。
