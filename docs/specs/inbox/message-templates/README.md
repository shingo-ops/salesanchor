## 概要
- 人間が作成・管理する定型文(テンプレート)の設定画面と、受信箱からの呼び出し・入力欄への転記を担う。
- AI翻訳は使わない(翻訳の用語集は translation-glossary が正本・本テーマとは独立)。
- なぜ既存で足りないか: translation-glossary はAI翻訳の用語集のテーマであり、人が書く文章ひな型の管理・呼び出しはどの既存テーマにも定義が無いため新設する。
