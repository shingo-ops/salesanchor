# 種別マスタ（product_type）

> 商品マスタが直接参照する、2層の種別台帳。
> 大分類を土台にしつつ、会社ごとの独自の種別を追加できる。

---

## 1. 役割

種別マスタは、商品を実務上の分類で扱うための台帳。
商品マスタはここから 1 つを選んで持ち、在庫・取引・画面表示の共通語にする。

- 例: ヴァイス、ポケカ、遊戯王
- 目的: 会社ごとの呼び方差を吸収しつつ、商品登録の入力を軽くする

## 2. 2層の扱い

| 層 | 内容 | 編集権限 |
|---|---|---|
| 共通 | 全社で共通の代表値 | 運営のみ |
| 会社独自 | その会社だけの追加値 | その会社 |

共通と会社独自は同じ台帳に同居するが、見える範囲は分ける。

## 3. 基本項目

| 項目 | 内容 |
|---|---|
| code | 種別コード |
| product_category_code | 大分類コード |
| name_ja | 日本語名 |
| sort_order | 表示順 |
| owner_tenant_id | 共通か会社独自かを示す |
| is_active | 利用中かどうか |
| note | 補足メモ |

## 4. 使い方

- 商品マスタは大分類の下で種別を選ぶ
- 会社ごとの入力ゆれはここに寄せる
- 選択候補は過去の登録実績を優先する

## 5. 運用ルール

- 会社独自の値は他社に見せない
- 参照中の値は物理削除しない
- 廃止は非表示で扱う
