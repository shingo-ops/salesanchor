# 商品分類の決定記録

## 1. 決定したこと

1. 商品の大枠は `product_category` で持つ
1. 商品マスタが直接参照するのは `product_type`
1. `item` は発送ラベル用の品目名として残す
1. `product_category` は全社共通のみ
1. `product_type` は 2 層で、会社独自追加を許す

## 2. 理由

- 大分類は棚そのものの概念なので、会社ごとに増やすと分類軸が壊れる
- 種別は会社運用の差が出やすいので、共通値だけに固定すると入力が詰まる
- 商品マスタの参照先を `product_type` に寄せると、在庫・取引・検索の共通化がしやすい

## 3. 捨てた案

| 案 | 却下理由 |
|---|---|
| 種別を 1 層だけにする | 会社独自の運用差を吸収できない |
| 大分類を会社ごとに追加可能にする | 全社で同じ棚の概念が崩れる |
| 品目に種別も統合する | 発送ラベル用語と商品分類の役割が混ざる |

## 4. 影響

- 親 README の §4 を 5 マスタ構成に整理できる
- 大分類と種別の責務が分かれる
- 図は「棚」と「引き出し」で説明しやすくなる
