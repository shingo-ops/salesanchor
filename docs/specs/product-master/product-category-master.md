# 大分類マスタ（product_category）

> 商品の大分類を管理する、全社共通の正本。
> ここは会社ごとの独自追加を許さず、運営だけが編集する。

---

## 1. 役割

大分類マスタは、商品を大きな棚で分けるための台帳。商品マスタはこの値を 1 つ選んで持つ。

- 例: トレカ、フィギュア、カメラ
- 目的: 商品群の大枠をそろえ、種別・品目・輸送ルールの前提を安定させる

## 2. 2層の扱い

大分類マスタは例外的に 1 層のみ。

- 共通行のみ
- tenant_004 / tenant_006 だけが編集できる
- 各社の自由記述追加はない

## 3. 基本項目

| 項目 | 内容 |
|---|---|
| code | 大分類を表す固定コード |
| name_ja | 日本語名 |
| sort_order | 表示順 |
| is_active | 利用中かどうか |
| note | 補足メモ |

## 4. 使い方

- 商品マスタは大分類を 1 つ選ぶ
- 種別マスタは大分類にぶら下がる
- 検索・集計・画面表示の見出しに使う

## 5. 運用ルール

- 会社ごとの追加はしない
- 名前の揺れは運営が吸収する
- 廃止時は物理削除せず非表示で扱う
