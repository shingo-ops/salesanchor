# rule-enforcement あるべき姿（PO の言葉）

- 親: [README.md](./README.md)

> この文書は何か: 決まりを機械の検査に変える取り組みで、PO が望む姿を PO の言葉のまま残したもの。

## PO の言葉（2026-10-27）

- 「とにかくルールと機械的な防止策が最重要で目的はルールを破った方法で手戻りをなくすことを実現したい、誰がやっても必ず決められたルールが守られてルール違反したものが本番に反映されることを防ぐ再現性についてエビデンスが欲しい」
- その前の問い: 文書を足すとき、提出時に機械で止めるだけでなく、作成前に決まりを読ませる仕組みと、提出前にチェック項目を確かめてから提出する仕組みがあれば完璧ではないか

## あるべき姿

- 本番に出る道はすべて、決まりの最後の関所（main の必須チェック）を通る。作業した道具（手元の Claude Code・クラウドの Claude・Codex・人の手）に関係なく、同じ検査で止まる
- 作業中・提出前には、最後の関所と同じ検査が先に走る。手戻りを減らすための補助で、守りの本体ではない（基準を書き写さない）
- 機械で判定できない決まりは「止めない」と理由付きで仕分ける。仕分けていない決まりは残さない
- 決まりを足すときは、守らせ方を決めないと取り込めない
