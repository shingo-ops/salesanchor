## 境界
- 本テーマは recon の「中身＝何を必ず調べるか」を定義する正本。新しい実行役（別エージェント）は作らない。recon は設計パートナーが通るモードである（design-partner.md §3）。
- recon の手続き上のルール（Phase2の位置づけ・完了定義）は STANDARD-WORKFLOW.md §1/§2 が正本。本書はそれを置き換えず、観点の網羅を担う。
- 既存の ADR-039（コード調査）・ADR-035（外部状態検証）は本書から指すのみで、内容を書き写さない。

## なぜ既存で足りないか（新規作成の理由・1行）
recon のルールが STANDARD-WORKFLOW §Phase2/§2・design-partner.md §4/§6・ADR-039・ADR-035 の複数箇所に分散し、「毎回必ず調べる観点」を束ねた正本が1つも存在しなかったため。
