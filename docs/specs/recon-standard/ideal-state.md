## あるべき姿（PO自筆・情景のまま）

reconで調査漏れが起きると、後のdesignがズレて設計が全部台無しになる。だから現状を、事実ベースで漏れなく把握したい。たとえばフロントエンドなら「現状のフロントはどう書かれているか」「共用パーツはどう書かれ、どう管理・維持されているか」「共用でないパーツはどうか」を調べ、設計図（あるべき姿）と照らし合わせて、足りないものは差分を埋め、優れているものは採用していく。そういう調査を、毎回信頼できる形でやりきりたい。
