# お客様の住所フォームと住所の決まり（customer-address-form）

> この文書は何か：お客様が自分で住所を登録するフォーム（/register・/register/address・/register/change-billing）の見た目と、送り先の住所の決まり（1行35文字以内・英字と数字と記号だけ）の表紙です。

親: [../README.md](../README.md)（索引の「請求先/配送先の住所区別」の行）

## 概要

お客様が英語のフォームで請求先と送り先を登録する → 送り先は FedEx がそのまま受け取れる形（1行35文字以内・最大3行・英字と数字と記号）でしか入らない → 社内の画面から入れる送り先も同じ決まりで守る。

## 境界

- 対象（第1段・PC）: 3つのフォームの並べ方と欄の幅、言語切替の位置、国番号の欄、請求先の住所3、送り先の35文字と文字の種類の決まり、見積書の紙の住所3、社内の会社の画面の住所の窓と注文ごとの発送の欄の決まり
- 対象外（第1段）: スマホの見た目（PC の後で別に行う）、今ある決まり外の住所の書き換え（PO 決定 D6：次に直す時に赤くなるだけ）、FedEx へ住所を渡す仕組みそのもの
- DB の表・列は増やさない（住所3の列は既にある）
