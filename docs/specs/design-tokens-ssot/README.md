## 境界
- 本テーマは「パーツの索引化・重複排除」を扱う。個別パーツ種別（色・文字等）ごとの差分設計は、本テーマの子として種別ごとに別途作成する（例: 色パーツの差分設計は docs/specs/design-tokens-ssot/color/ 等）。
- 便0.5（docs/specs/design-system/）は、色パーツのうち「カレンダー色・ロール色」に限定した命名確定作業であり、本テーマが優先する設計仕様書として位置づける（本テーマ§ideal-state.mdのAが確定方針）。
- recon証拠は docs/handoff/color-tokens-ssot/recon.md（色パーツ・7観点＋TS/TSX追加調査・PR #2864でマージ済み）を参照する。

## なぜ既存で足りないか（新規作成の理由・1行）
既存の docs/specs/design-system/ は色パーツの一部（カレンダー・ロール）の命名確定のみを扱っており、9種別（色・文字・アイコン・コンポーネント・文字サイズ・値・アニメーション・グラフ・ページ構成）を横断する索引化・重複排除を扱う正本が存在しなかったため。
