## 2. KGI（PO が画面を開いて ○× を一義に判定できる合格条件）

範囲: モデルケース branch-operations 一式で判定。

| # | 合格条件 | 測り方 | 合格ライン |
|---|---|---|---|
| ① | 子→親の戻りリンク | recon.md / design.md のうちリンクが在るファイル数 | 2/2 |
| ② | 親→子の一覧リンク | 親に載る子リンク本数 ÷ 並ぶべき子文書数 | 満数 |
| ③ | 素人向け1行説明 | 対象ファイル中、1行説明が在るファイル数 | 全数 |
| ④ | 索引から辿れる | 親→子への到達経路 成立数 | 満数 |
| ⑤ | 正本に明文化 | 該当節の有無 | 1（在=1／無=0） |

KPI = 達成KGI数 ◯/5。進捗表も「5項目中いくつ緑か」で塗る。
