# あるべき姿（PO承認・2026-07-09）

本文はPlanner（設計パートナー）が対話内容からまとめ、PO（しんご）が承認した願いである。以降この文を正本とし、Planner・Generatorは書き換えない。

## 本文

このアプリのデータは、「同じ事実は、この世にただ1か所にだけ存在する」状態になっている。

売上予測も、会話の記録も、金額も、お客さんの情報も——どんな事実も、それを記録する正本の場所がただ1つに決まっている。他の場所で同じ情報が必要なときは、コピーを持つのではなく、その1か所を見に行く（背番号で参照する）。

だから、どこか1か所を直せば、それを見ている全員が自動的に最新を知る。「こっちには古い数字、あっちには新しい数字」という食い違いが、そもそも起こりようがない。

この状態によって、分析が常に正確になり、データの二重入力や更新漏れがなくなる。バラバラのスプレッドシートやGASで別々に管理していた情報が、1つの正しい土台に統合され、機能を最大限に引き出せる。
