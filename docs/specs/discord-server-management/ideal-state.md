#### 辞めたときの要件（2026-11-05 の PO の決定から）

- アプリでスタッフを「消した」とき＝辞めた。Bot はその人から Bot が管理するロールを外し、自社サーバーから外す（Kick。招待があれば入り直せる。出入り禁止にはしない）
- 「無効」にしたときは、Bot が管理するロールだけ外す。サーバーには残す（休職などで戻る人のため）
- アプリで Discord の番号を別の番号に書き換えたときは、元の番号の人から Bot が管理するロールを自動で外す。サーバーからは外さない（選択肢 1 の「サーバーには残す」）
- 消す前に、確認の窓を必ず出す。Discord の番号が登録された人なら、確認の窓に「Discord の自社サーバーからも外れます」と書く
- 外すのは自社サーバーだけ。顧客用サーバーからは外さない。消した人以外（登録していない人）には今までどおり触らない
