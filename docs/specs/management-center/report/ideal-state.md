
# あるべき姿（PO自筆・原文のまま・2026-07-15）

本文はPO（しんご）の言葉が正本である。Planner・Generatorは書き換えない。
親: [../ideal-state.md](../ideal-state.md)（管理センター）

## 原文（目的・PO自筆）

商談終了した後のレポートを管理者が管理して確認できるページ

## 原文（表示のみの方針・PO自筆）

見るだけ（他のページで作られたレポートを、ここに一覧表示するだけ）
一覧表示のみでデータテーブルでリストとして、行をクリックすると詳細が確認できるページにしたい

## 原文（詳細の内容・PO自筆）

成約結果、顧客名、担当者、商談カルテに入っている内容全て、成約結果の理由、担当者の振り返り
（商談カルテ＝顧客管理の顧客カルテのこと）

## 原文（一覧の列・並び順・PO自筆）

メインページにも成約結果、国、取り扱い商材は表示させてくれ
成約結果は1番左側、担当者は商談日の右側、国は顧客名の左側に設置

## 原文（絞り込み・並び替え・PO自筆）

担当者ごとに絞り込む機能も追加、テーブルヘッダーをクリックすると昇降並び替えする機能も持たせたい
取り扱い商材で絞り込む機能も欲しい

## 原文（商談カルテの内容・PO自筆）

商談カルテをもう少し見やすくデザインを描いてくれ

レポートは新規営業のレポートなので取引回数は含まない。その代わり会話の回数はカウントして表示しておいてほしい

最終接触は不要、単純にカルテの情報を表示したいので
顧客名
国
流入元
取扱タイトル
販売形態
返信速度
顧客タイプ
規模感
温度感
競合確認
月間見込み金額
課題・ニーズ
商談メモ
