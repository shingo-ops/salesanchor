## 境界（他テーマとの取り決め）

- 管理センター＝全データの基盤管理（CRUD＋CSVインポート/エクスポート）に特化。「データセンター」の役割。
- 顧客管理（customer-management）等の分析・優先度づけ機能（CRM）とは意図的に役割を分ける。「顧客」項目はデータ管理に含むが、基盤のCRUD＋CSVのみを扱い、分析機能は顧客管理テーマが担う（PO 2026-07-15確認）。
- 外部連携（Google/メッセージ/配送/決済）はデータテーブル形式ではなく、接続設定がこのメニュー内で完結する別形式。
