## 運用方針
- 報告できるのは super admin だけ（PO 2026-10-17「n」）。
- 正答の判定は AI の感想ではなく、報告で入った正解との機械照合で行う。

## 設計フェーズ送り事項
1. 解決（PO 2026-10-17「y」）: 数量・価格は数字で入力し完全一致で照合。メモはメモ語マスタ（tcg_note_master）から複数選び、語の集合で照合する。
2. 「正しい商品がマスタに無い」と答える選択肢 → 新商品登録（PO の Discord y）へ回す。
