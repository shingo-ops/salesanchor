# あるべき姿（正本）

本文はPO（しんご）の言葉が正本である。Planner・Generatorは書き換えない。
初回承認: 2026-07-03（旧テーマ本体4項・追記1）／移植承認: 2026-07-04

1. **受注後の調達は、人間が深く考えなくてもよい。** 受注が入ったら、
   「自社在庫で出す／A社から海外直送／A社+B社から取り寄せて発送／
   A社+C社+自社を同梱／A社は海外直送・残りは自社在庫を別梱」——
   こうした選択肢をシステムが整理してくれて、受注後の仕入れがスムーズに進む。
   調達ルートが費用つきで見える状態。

2. 発注後に「在庫がない」と言われても、システムが即座に次の候補を組み直して
   提示し、商談も仕入れも止まらない。売ろうとしている在庫は、確定の直前に
   鮮度を確かめられる。
