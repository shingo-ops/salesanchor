# あるべき姿（正本）

本文はPO（しんご）の言葉が正本である。Planner・Generatorは本文を書き換えない。
承認日: 2026-07-03

## 本体

1. **在庫が2種であることが常に明確。** 自社在庫とドロップシッピングの
   共用在庫が区別され、「今、どの在庫が、いくらで、どれぐらいあるのか」が
   迷わず分かる。
2. **商談のリズムを崩さない。** 在庫の答えを即時に顧客へ伝えられ、
   見積もり・請求書も即時発行できる。
3. **共用在庫はガラス張り。** 誰が・何を・いくつ・いくらで保持しているか、
   送料はいくらか、海外代行手数料はいくらかが明確に分かる。
4. **受注後の調達は、人間が深く考えなくてもよい。** 受注が入ったら、
   「自社在庫で出す／A社から海外直送／A社+B社から取り寄せて発送／
   A社+C社+自社を同梱／A社は海外直送・残りは自社在庫を別梱」——
   こうした選択肢をシステムが整理してくれて、受注後の仕入れがスムーズに進む。
   調達ルートが費用つきで見える状態。

## 追記1（在庫ズレ耐性・2026-07-03承認）

発注後に「在庫がない」と言われても、システムが即座に次の候補を組み直して
提示し、商談も仕入れも止まらない。売ろうとしている在庫は、確定の直前に
鮮度を確かめられる。

## 追記2（在庫解析・2026-07-03承認）

ドロップシッピングの在庫と価格は、自社専用のログとして株価チャートの
ように蓄積される。変動はシステムが検知して提案の材料として営業に知らせ、
さらにエージェントが顧客と在庫の状況を突き合わせて「今、この顧客に
これを提案してください」と根拠つきで助言してくれる。
