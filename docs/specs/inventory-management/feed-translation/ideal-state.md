# あるべき姿（正本）

本文はPO（しんご）の言葉が正本である。Planner・Generatorは書き換えない。
起票日: 2026-07-05

## 1. 解析と信頼（PO自筆）

提供元メッセージのあるべき姿は全てのテナントから送られてくるメッセージを正しく解析して整形して棚に置くこと。
提供元ごとに商品名、単位、状態、価格、在庫数など書き方が異なるのでそれを正しく解析して整形して集計する。
推測で解析をせずに事実に基づいた解析をする、不明なものは解析できなかったと人間に報告して、
人間が正しく解析できるためのルールや情報の更新を行う。
提供する在庫情報は信頼があり、誤った情報を届けてはならない。

## 2. 商品名のゆれと育つ仕組み（PO自筆）

商品マスタも絡めて商品名の揺れについても解析できるようにしたい。
ブラックボルトをブラボと書かれてもブラックボルトと認識できる、
ブラックボルトとブラックボルトDXが並んでいてもそれぞれ違う商品だと認識できる、
黒炎と書かれていても黒炎の支配者のことだと認識できる、
ARバルクとSARバルク、PSA10 ARバルクが並んでいてもそれぞれ違う商品だと認識できる、
認識ができないものは認識できなかったリストとして人間に判断をしてもらい、
辞書の更新を求めるなど長期的に育ちながら解析精度が成長する、
AIが解析した認識と人間が出した正解をRAGとして溜め込むなど
徐々に人間が判断しなくてもAIが賢くなり自動化していくツールにしたい。
