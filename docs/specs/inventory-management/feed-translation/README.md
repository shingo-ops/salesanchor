## 境界（どこまでがこのテーマか）
- 本テーマ: 受信 → 事実に基づく解析 → 未解析の人間報告と辞書育成 → 人間承認（免許制） → 承認済みの値をA（今の値）・C（歴史）へ置くまで。
- 本テーマ外: 置かれた後の「変化の検知・顧客への提案」は inventory-analytics の領分。
- 解析品質の分析（提供元×商品の成績表）は本テーマ内。在庫・市場そのものの分析は inventory-analytics。
