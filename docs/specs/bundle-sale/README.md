# まとめ売り（N単位セット）の読み取り（bundle-sale）

> この文書は何か: 「40パックセット/¥24,000 残り15」のような、いくつかをまとめて1つの値段で売る行を、全商品で同じ形（商品名＋40パックセット／中身の単位／まとめ1つの値段／まとめの数）で保存・表示する仕組みの表紙。

- あるべき姿（PO の言葉のみ）: [ideal-state.md](./ideal-state.md)
- KGI: [kgi.md](./kgi.md)（PO 合意 2026-10-17）
- 子文書: [recon.md](../../handoff/bundle-sale/recon.md)・[design.md](../../handoff/bundle-sale/design.md)
- 関係する決定: ADR-1021（バルク系の状態 Bulk と便2 の1枚単価換算。便2 は本テーマの ADR 案で置き換える）・ADR-1014（在庫表は配信行を見せる）・ADR-1019（閲覧ページ）・ADR-1007（値は migration でなく記録した SQL で入れる）・ADR-027（i18n）

## 境界
- 対象: v102 解析の保存（analysis_results）、単価の確かめ（相場の区切り）、配信（GAS 在庫一覧・閲覧ページ・アプリ在庫表の商品名の欄）。
- 対象外: 「100枚 / 50セット @24,000」型（まとめ語が無い）、「150枚入」「カートン(20BOX入り)」、在庫数の「×N」。今の保存のまま人が見る。比較・レビュー画面での表示と人による直しは便4（別設計）。
