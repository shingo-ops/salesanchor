| # | 原文の言葉 | 合格条件 |
|---|---|---|
| T1 | 「チームメンバーが今何をやっていて、今日は何をやっているのか」 | ボードで各メンバーの **①対応中の作業（presence）②自分ボール件数と最長経過時間 ③今日の行動 完了/予定** が**ゼロ操作で見える**。表示は受信箱・やることフィードと**同一源泉（食い違い0件）**、メンバーによる手動の状況更新 **0**（入力させない・原本から導出） |

## 確定事項（KGI導出時のPO決定）

- **管理単位＝ボール**（2026-07-03 PO合意「ボール型はいい提案で合意」）：自分ボール／相手ボール／無担当ボール。物差しは時刻でなく**経過時間**。
- ボールの原本は受信箱（conversation_logs）。本ページは表示専用＋割当操作のみ（新規入力ゼロ・SSOT）。
- 「今日の行動 完了/予定」は dashboard **D10 カスケードの日次行動量と同一値**を表示（二重計算しない）。
- ページ配置：サイドメニュー並列（「ページ＝メニュー、レンズ＝タブ」規則。正本は README 憲章）。

## 設計送り事項（③〜⑤で決める）

- presence（「対応中」）の導出方式（受信箱の開封・最終操作からの推定等。手動ステータス入力は不採用が前提）
- 無担当・放置の**警報閾値（◯分）**——運用開始後にPOが設定（と正直に明記）
- ボール0＋行動完了メンバーへの次アクション提案（dashboard D8 との接続）
- スマホでの見せ方（ボトムナビ候補・schedule のスマホ操作感と歩調を合わせる）
- リアルタイム更新の方式（ポーリング間隔等）
