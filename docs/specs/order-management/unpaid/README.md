# 設計仕様書:受注管理(未入金)

> この文書は何か(素人向け1行説明):請求書発行後の未入金案件を、支払期日・催促・入金確認・次の移動先まで迷わず追えるようにする子テーマの表紙です。

- 親テーマ: [../README.md](../README.md)
- あるべき姿（POの言葉のみ・正本）: [ideal-state.md](./ideal-state.md)
- KGIと運用: [kgi.md](./kgi.md)
- 画面設計: [design.md](./design.md)
- 定点観測台帳: [track-record.md](./track-record.md)
- ステータス: KGI承認前。未入金ページの画面・文言・運用の正本をここに集約する。

## 境界
- この子テーマが扱うのは請求書発行後の未入金案件だけ。
- Order の所属管理と入金実績の正本は親テーマと取引フローが持つ。
- 仕入れ・発送・商品到着・トラブル・キャンセルの詳細は扱わない。

## 維持の仕組み
- ideal-state.md はPOの言葉のみで構成し、Planner・Generatorは書き換えない。
- kgi.md の数値が変わる場合は design.md の見せ方とセットで見直す。
- 画面骨格を変えるときは親テーマの子文書一覧も更新する。
