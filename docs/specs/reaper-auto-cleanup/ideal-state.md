# あるべき姿（正本・PO自筆）

親: ./README.md

> この文書は何か（専門用語なしの1行）:
> 掃除機（reaper）がどう動いてほしいかを、POの言葉のまま書いた願いの正本。

## あるべき姿（PO自筆・情景のまま）

reaperが、本店の実worktreeを毎回もれなく正しく見て、消してよい物だけを安全に消し、消せない異物（空箱・ラベル欠け）は人が気づける形で表に出す状態。
掃除機が別部屋に入らない（配線が本店を向く）。本物のworktreeは1件残らず数える。worktreeでない異物は「異物」として名指しで報告され、棚に埋もれない。
1日1回ではなく都度消す、もしくは基準値を決めておき溜まったら自動で消す。

## タイミング方式（PO決定・2026-07-22）

都度＋溜まり対策の二段構え。
- 主: マージ後に即時掃除（既存の repository_dispatch: reaper-run 配線を使う）
- 副: Mac オフ等で取りこぼした分を 1日1回の定期掃除が拾う
- 監視: 溜まり過ぎ防止に見張り（ghost-count）を定期jobへ繋ぐ

## スコープ外（既知の弱点・別テーマ）

即時掃除・定期掃除とも self-hosted runner（PO の Mac）上でのみ動く。Mac が電源オフの間はどちらも動かない。
本テーマの合格ラインは「Mac がオンの間は確実に動く」とし、電源依存の解消（クラウド実行への移行等）は別テーマとして切り出す（2026-07-22 PO決定）。
