# KGI — 認証・権限・ロール

この文書は、「システム管理者を通常の会社に見せない」が達成できたかを ○× で判定する条件です。

親: [README.md](README.md)

状態: PO 承認済み（2026-10-10 チャット「y」）

## KGI（○× で判定）

| # | 条件 | 判定のしかた |
|---|---|---|
| K1 | super admin でない人がロール一覧の画面を開くと、「システム管理者」が出ない | 画面（Evaluator）と API の試験 |
| K2 | super admin でない人のスタッフ追加・編集のロール選択に、「システム管理者」が出ない | 画面（Evaluator）と API の試験 |
| K3 | super admin でない人が API で直接「システム管理者」を付けようとしても、付かない（拒否される） | API の試験 |
| K4 | super admin の人には、今どおり「システム管理者」が出て、付けられる | API の試験 |
| K5 | ほかのロール（オーナー・マネージャーなど）の見え方・付け方は変わらない | 既存の試験と画面 |
| K6 | 「システム管理者」ロール自体は消さない（5社の行と目印 admin は残る） | 本番の読み取り（5社×1行） |

## 運用方針
- 見分けは目印（system_key = admin）で行う。ロールの名前では見分けない。
- 隠す目印の一覧はコードの定数1か所に置く。

## 設計送り事項
- スタッフ一覧のロール名の列は、本番で「システム管理者」を持つ人が 0 人（2026-10-09 読み取り）なので、今回は扱わない。
