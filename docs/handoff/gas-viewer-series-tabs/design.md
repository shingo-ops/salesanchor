# design: 顧客向け在庫一覧GAS — Seriesタブ追加・スマホで提供者を表示

- 状態（2026-10-05）
  - 設計: Opus が作成し、自分で審査した（同じAIによる審査で、独立した第三者のレビューではない）
  - PO: 実装を承認済み
  - 反映: テスト用は版14、本番は版12で、どちらも反映済み
- 根拠: [recon.md](recon.md)
- 関係するADR: ADR-067、ADR-144

## 目的（POの言葉）
1. PC画面のテーブルにタブを置き、「全て」「ポケモン」「ワンピース」などSeriesごとに絞り込めるようにする
2. スマホにも提供者名を表示する

## 変更内容
- サーバー（Code.js）: 許可リストの末尾に `'Series'` を追加する（12列）。
  - 既存の列の順番は変えない。
  - 画面側の `COL` 配列の位置もずれない。
- 画面（index.html）
  - タブ置き場 `#seriesTabs` を追加する。
  - `buildSeriesTabs()` を追加する。
    - 読み込んだ行（Sold out を除く）の Series の値からタブを作る。
    - 並び順は件数の多い順、同数なら名前順。
    - 件数は表示しない。
  - 絞り込み `render()` に、選択中の Series で絞る条件を追加する（既存の条件とAND）。
  - Series が1件も無いときは、タブ置き場を `hidden` にする。
  - 提供者の列は `mobileHidden` をやめて `mobileOrder: 6` にする（スマホのカードで、備考の次に表示）。
- 見た目（ADR-067 準拠）
  - `:root` に正本トークンを15個転記する。名前も値も正本と同じにする。
    - 出どころ: origin/main a34381937 の `frontend/src/tokens.css` と `frontend/src/index.css`（ライト側）
  - タブの CSS は `Tabs.css` の underline／md の写しにする。
    - 色の直書きは0。
    - px の直書きは、金型と同じ 1px／-1px と、@media 640px（ADR-067 で許可された例外）だけ。

## 選んだ方法と、選ばなかった案
- タブの元データは、シートの Series 列にする。
  - 理由: Series 列は SA の中分類マスタ（type_master）から配信されている。新しく接続先やデータのコピーを作らずに済む（データの置き場所を1つに保つ）。
  - 選ばなかった案: GAS から中分類マスタを直接読む案。GAS から DB や API への新しい接続が必要になり、データの通り道が2本に分かれるため。
- タブの件数表示はやめた。
  - 理由: 初期状態では「24時間以内」の絞り込みが ON なので、タブに出る件数と実際の行数が食い違うため。
- 既存部分の色の直書き（105箇所）は今回は変えない。
  - 理由: 全部をトークンに置き換えるとアプリ全体の見た目が変わるため、別に PO の判断が必要。

## リスクと対処
- 本番シートに Series 列が無い場合 → タブ置き場を非表示にするだけで、画面は崩れない。
- まだ公開していない編集が一緒に出てしまう → 反映前に、公開中の版とリモート HEAD の diff が空であることを確かめた（本番の版11、テストの版13）。
- 反映に失敗した場合 → `clasp redeploy <ID> -V 11`（本番）または `-V 13`（テスト）で、URL を変えずに戻す。
