# design: gate-message-clarify

## 方針（A案：ラベル不変・説明追記）
記入欄ラベル「削除するファイル:」は変更せず、エラーメッセージの文言のみ明確化する。ラベル改名（B案）は進行中PRが関所で引っかかるリスクがあるため不採用。

## 変更内容（scripts/check-process-artifacts.js、3点）
1. 「削除が無い場合は…」→「行の削除・変更が無い場合は…」（旧:674）
2. 「削除するファイル:」記入を促す行の直後に注意書きを1行追加：「※「削除するファイル」とは、丸ごと消したファイルだけでなく、1行でも削除・変更した行があるファイルを指します」
3. 「意図しない削除を除去してください」→「意図しない変更を除去してください」（旧:680）

判定ロジックは不変。出力文字列のみ変更。node --check で構文健全性を確認済み。

## 外部・過去事例欄
- 「exists ≠ working」原則：仕組みが「在る」ことと「正しく伝わる・動く」ことは別。今セッションF1（alert rules も webhook も在ったが監視データが届かず沈黙）と同根。本件も「削除照合ロジックは在って正しく動くが、メッセージが誤読を生む」状態。
