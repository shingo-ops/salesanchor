## 1. 目的（PO の言葉と経緯）

- 2026-10-31、PO が選んだ問い:「解析の誤りは何で起きやすいか」。
- 背景: PO はデータ分析の募集をきっかけに、いくつもの原因が同時に動いたとき、どれが何割効いたかを計算で出す考え方（回帰分析）を学び、事業に取り入れたい。
- 目的は2つ。(1) どこを直すと誤りが一番減るかを数字で知る。(2) PO 自身がこの考え方を身につける。(2) の説明の形は設計で決める。

## 3. 成功の条件（KGI。PO 承認済み 2026-10-31）

| # | 基準 | 検証方法 |
|---|---|---|
| KGI-1 | 正解表 1,494 行すべてに、項目ごとの正誤と原因の候補が1行に並んだ表ができる | 表の行数が 1,494。原因の候補の列に空欄が 0（空欄が出る候補は設計で扱いを決める） |
| KGI-2 | 誤りを増やす原因の上位3つが、「その原因で誤りが何倍になるか」と「95% の確かさの幅（下限・上限）」つきで1枚の表に出る | 表に3行あり、各行に効き目・幅の下限・幅の上限が入っている |
| KGI-3 | 上位3つとも、偶然では説明できない | 3行すべてで、幅の下限が 1 倍より大きい（＝効き目なしの 1 倍を幅がまたがない） |
| KGI-4 | 同じ材料で2回計算すると、結果が1字も違わない | 2回の出力の sha256 が全ファイルで一致 |
| KGI-5 | 社外秘の中身がリポジトリ・PR に載らない | PR の差分に仕入元名・投稿 id・行ごとの正誤が 0 件 |

KGI-3 が満たせなかった場合も、計算した表はそのまま PO に見せる。「3つとも偶然とは言えない原因は見つからなかった」も事実として報告し、数字を作らない。
