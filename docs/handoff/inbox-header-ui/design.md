- 事例1: 送信ガード Phase A（ADR-143）の実装時にトグルUI → プルダウンUIへの変更は既存の `.inbox-platform-select` スタイルを再利用することで追加CSSゼロで対応可能と判断。PRD由来のUI簡潔化要求に対し既存コンポーネントパターンを適用。

## 技術 How・KPI

- KPI: E2E 8/8 PASS・frontend lint SUCCESS・ヘッダーボタン数 = 1（未読のみ）
- 技術選択: 既存 `.inbox-platform-select` を再利用（追加CSS不要・既存スタイルの一貫性維持）

## 弊害・トレードオフ

- ヘッダー直置きのアーカイブ・削除を撤去することで、1クリック到達が三点メニュー経由（2クリック）になる。ただし一括選択バーは変更なしで引き続き使用可能。
