## 台本の全文
`/tmp/recon/p07b_p12_py.py` の P7 部分:
```python
rows = []
for fn in sorted(os.listdir('migrations')):
    if not fn.endswith('.sql'):
        continue
    raw = read('migrations/' + fn)
    body = strip_sql_comments(raw)
    lines = body.split('\n')
    t = [x for x in ('tenant_001', 'tenant_004') if re.search(x + r'\b', body)]
    if not t:
        continue
    for i, ln in enumerate(lines, 1):
        m = re.search(r'CREATE\s+(?:TEMP\w*\s+|UNLOGGED\s+)?TABLE\s+(?:IF\s+NOT\s+EXISTS\s+)?([\w."%{}$]+)', ln, re.I)
        if m:
            rows.append((fn, i, m.group(1), ','.join(t), regfiles.get('migrations/' + fn, '-')))
```
