## 台本（概要）
`/tmp/recon/p04.py`: `PAT` の辞書（`GRANT_ALL`・`DEFAULT_PRIV`・`CATALOG_LOOP`・`RLS`・`POLICY`・`GRANT`・`VIEW`・`DROPCOL`・`ALTERTYPE`・`DROPTABLE`）の正規表現を、コメント除去後の各行に当て、ファイル別・パターン別の行番号を `p04_hits.json` に出す。
- `VIEW`: `\b(CREATE\s+(OR\s+REPLACE\s+)?(TEMP(ORARY)?\s+)?(MATERIALIZED\s+)?VIEW|DROP\s+(MATERIALIZED\s+)?VIEW|ALTER\s+(MATERIALIZED\s+)?VIEW|REFRESH\s+MATERIALIZED)\b`
- `GRANT_ALL`: `\bON\s+ALL\s+(TABLES|SEQUENCES|FUNCTIONS|ROUTINES)\b`
- `DROPCOL`: `\bDROP\s+COLUMN\b`、`ALTERTYPE`: `\bALTER\s+COLUMN\s+[\w"]+\s+(SET\s+DATA\s+)?TYPE\b`、`DROPTABLE`: `\bDROP\s+TABLE\b`
`p04b.py`: `FOR x IN` の行から4行先までに `pg_tables|information_schema.tables|pg_class|...` があるものを OBJ、`schemata|pg_namespace|tenant_` があるものを SCHEMA として数える（155 の繰り返しのうち OBJ 23・SCHEMA を含むファイル 125）。
`p04c.py`: `EXECUTE|format(` の行の前後2行に `ROW LEVEL SECURITY|GRANT|CREATE POLICY|VIEW|OWNER TO|SET SCHEMA` がある物を拾う（35ファイル）。
`p04d.py`: 入れる4本の `p04_hits.json` を引いて ○× を出す。
（各台本の全文は /tmp/recon/ にあり、本ファイルは概要にとどめる。再現は `common.py`（`p06.md` に全文）と上の正規表現で足りる。）
