# 合格条件: 決まりを「1本の木」にする

> この文書は何か（専門用語なしの1行）: 「AI が毎回同じ道で決まりの細かいところまでたどり着く」を、数で合否を決められる形にした案。

状態: **PO 承認済み（2026-11-04）**。経緯: Opus が「この案で合格の線を決める」を選択肢1【おすすめ】として示したのに対し、PO 原文「1」。根拠の数は [recon.md](./recon.md)。

承認の後に分かった訂正（合格の線は変えない）:
- G5 の「今」は、承認のときに 11 と示したが、既存の CI と同じ数え方で範囲を広げると **1**（docs/agents/generator.md）。11 はリンクと `docs/…md` の書き方だけで数えた別の数え方の数（recon §4）。
- G1 の「1 か所」は、`~/kb/00-rules` の返事の決まりの1つの置き場を指す。中は、毎回読むファイル（chat-layout.md）と、入力のたびに見張りが表示するファイル（chat-format.md「言葉の選び方」）の2つに分かれ、同じ話題は両方に書かない。見張りの変更は禁止のため、見張りが読むファイルは動かせない（design.md §2）。

| # | 測るもの | 今 | 合格 | 測り方 |
|---|---|---|---|---|
| G1 | 説明の決まりの本文がある場所 | 9 種類（recon §1） | 1 か所。ほかは「そこを見る」の1行だけ | 置き場ごとに本文の行を数える表を週1回作る |
| G2 | 説明の決まりどうしの食い違い | 6 件（recon §2） | 0 件 | 正本と、指すだけの行を照らす。食い違いの直し方: 返事の画面は短く（10/19 の決まり）、図と表はファイルやページに置いて場所だけ伝える（10/27 の決まりと両立） |
| G3 | 意図の読み方が毎回目に入るか | 入らない（指す1行だけ） | 入る（毎回読む場所か、入力のたびの表示に入る） | 新しい会話を1つ開き、最初に読まれた内容に入っているかを見る |
| G4 | 台帳の行番号が実物と合わない数 | 5 / 83（recon §3） | 0。合わなければ週1回の機械の点検が × を出す | 点検の台本に行番号の照合を足す |
| G5 | 入口からたどれない手引き | 11（recon §4）→ 正式な数え方で 1（上の訂正） | 0（使わないものは「使わない」と印を付けて木から外す） | recon §4 と同じ数え方を週1回の点検に足す |
| G6 | 2つの根で同じ話題を持つ数（どちらが正か書いていないもの） | 4 話題（recon §5） | 0。片方が正本、もう片方は指すだけ | 話題の表を台帳に持ち、週1回照らす |
| G7 | 正しい手引きを開く率（K12） | 12 / 20（目標 10 / 20） | 18 / 20 以上 | 同じ 20 題を流す。1回 約400円 |
| G8 | 毎回読む行数（K1） | 166 | 200 以下を保つ | 週1回の点検（今と同じ） |

対象外: 製品のコード・データ・画面。見張り・設定・許可の仕組みの変更（PO の禁止事項）。

直す場所のうち `~/.claude`・`~/kb` は PO が `!` で流す台本で直す。覚え書き（自動メモリ）は Opus が直す。リポジトリの中は PR で直す。
