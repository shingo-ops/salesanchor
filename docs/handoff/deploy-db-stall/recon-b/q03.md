## 事実（設計とのずれ）
`docker-compose.yml` に `build:` の行は**1つも無い**（`grep -n -E 'build|context|\./backend|dockerfile|image:' docker-compose.yml` の当たりは image: の行と :514 の init.sql の volume 行だけ）。設計 §17-1 の「build が ./backend のサービスは :63・:215・:310・:354」は今の姿と合わない。今は4つのサービスが同じ image を指す。下の表は「image が `${BACKEND_IMAGE:-astro-webapp-backend}` のサービス」で代用して並べる（build が ./backend のサービス、ではない）。
