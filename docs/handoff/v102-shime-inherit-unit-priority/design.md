# design: 規則12で、〆の件に単位語があればその状態を優先する（便3b）

- 状態: 設計案・Opus 自己審査済み（§9。独立した第二者レビューではない）。PO 2026-10-11「状態がある場合は状態を優先　y」（recon.md §1）。
- 参照: docs/handoff/v102-shime-inherit-unit-priority/recon.md、docs/handoff/v102-shime-direct-inherit/design.md（規則12）、docs/adr/ADR-158-product-level-supersession.md（在庫の最新は analysis_results.is_current の1か所）。

## 1. 目的と成功の判定
「〇〇 ボックス 完売」のように〆の件の行に単位語（ボックス・BOX・カートン・パック等）があるとき、前の在庫の別の状態を引き継がず、〆の件そのものの状態（単位語から決まる状態）を使う。前の2日間にボックスの在庫が無くパックの在庫だけがある場合に、パックの在庫を誤って完売にすることを防ぐ。

| KGI（○×） | 判定 |
|---|---|
| G1 件の行に単位語がある〆（`unit_basis.alias` あり・`from_condition` なし）は規則12で引き継がない | 単体テスト |
| G2 単位語が無い〆・単位語が状態から決め直された〆（`from_condition` あり）は今と同じ | 単体テスト・既存テスト全緑 |
| G3 recon.md §3-2 の 56 件のうち、12f が成立する 14 件だけが引き継がなくなり、残り 42 件は不変 | 等価確認（手元、unit_out.tsv を入力に足す） |

## 2. 規則（規則12に 12f を足す）
- 12f 〆の件の行に単位語がある（`unit_basis` の `alias` が None でなく、`from_condition` が無い）ときは引き継がない。〆の件の状態（単位語から決まった状態）をそのまま使う。
- `unit_basis` が無い件（テストの件など）は「単位語なし」として扱う（今と同じ）。

## 3. 変えない範囲
規則12a〜12e、便1/便2、読み込み、書き込み、配信、migration、画面。

## 4. コード
- `backend/app/services/gemini_raw_copy_v102_soldout_ref.py` の `_is_inherit_candidate`（:354-361 付近）に 12f の条件を1つ足す。判定は小さな関数 `_has_unit_word(item)` に分ける：`basis = item.get("unit_basis") or {}`、`basis.get("alias") is not None and "from_condition" not in basis`。
- テスト `backend/tests/test_gemini_raw_copy_v102_soldout_ref.py`：12f 成立で決めない（ボックス〆・パック在庫の形）、`from_condition` ありは今どおり引き継ぐ、`unit_basis` なしは今どおり。

## 5. 代替案と選んだ理由
| 案 | 内容 | 採否と根拠 |
|---|---|---|
| A 採用 | 単位語があれば引き継がない | PO の「状態を優先」どおり。単位語ありで正しく引き継いでいた 13 件は、v102 では〆の件自体が同じ状態になり在庫が外れる（recon.md §3-2）ので失うものが無い |
| B | 単位語の単位と引き継ぐ状態の単位が同じときだけ引き継ぐ | 不採用。パック系の状態はマスタで単位に結びついていない（line_conditions の Searched/Unsearched pack は unit_id なし）ため判定できない。A と結果の差が無い |
| C basis の文字で判定 | `R4:単位既定` を語扱い | 不採用。単位語が無い箱系の商品も同じ文字列になる（recon.md §2） |

## 6. 弊害とリスク
| # | 弊害 | 対策 |
|---|---|---|
| R1 | 単位語が〆とは別の行（価格の行など）にある件も「状態あり」になる | 件の行全体で単位を決めるのが今の v102 の仕様（〆の行は記録されない）。件の状態はその単位で決まるので、それを優先するのが PO 方針どおり |
| R2 | 測定（§3-1）は役割の付け直し無し等の近似 | 実行時は実際の `unit_basis` で判定するので近似は判定に入らない。G3 は影響の見積もり |
