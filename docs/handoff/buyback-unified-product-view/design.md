# Design: 買取相場 統一商品マスタ表示

## recon参照
docs/handoff/buyback-unified-product-view/recon.md

## ADR参照
ADR-027, ADR-144

## 変更内容
1. デフォルト表示を商品別に変更（viewMode 初期値 "product"）
2. タブ順序を「商品別」「店舗別」に入れ替え
3. 検索欄の幅を max-width: 200px で制約し水平配置を改善
4. 店舗別ビューの商品名表示を商品マスタ軸に統一（紐付け済み→マスタ名、未紐付け→店舗名+要確認バッジ）
5. 店舗別ビューに商品コードカラムを追加

## 対象外
- バックエンド変更（なし）
- by-product ビューの変更（既にマスタ軸）

## 受入条件
| 基準 | 検証方法 |
|------|---------|
| デフォルトが商品別 | ページ開いた時に商品別ビュー |
| タブ順序が商品別→店舗別 | 目視確認 |
| 検索とプルダウンが水平 | 目視確認 |
| 紐付け済みはマスタ名表示 | 店舗別でマスタ名が表示 |
| 未紐付けは要確認バッジ | Badge variant="warning" |

## 維持の仕組み
- 守り手: ADR-027 i18n CI、ADR-144 UIガバナンス CI
