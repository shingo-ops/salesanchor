## 最初に読むこと

このファイルを、完売ルールについてのPOとの認識合わせの再開入口とする。以下の「合意」は業務上の意味の合意であり、製品実装・DB変更・マージ・本番変更のGOではない。設計パートナーの範囲で進め、自動で実装役に切り替わらない。同一AIの自己審査を独立レビューとは称さない。

POの目的（原文）:
> 完売ルールページでは完売商品の一覧を見せるのではなくて完売を判定するルールを確認したり追加・修正・削除するためのページとして使いたい

進め方（原文）:
> 1つずつ明確にしていきたいので順番に詳細を素人に理解できるように質問してくれ、推測はせずに売切のルールをまず認識をすり合わせて確定冴えたい

最新回答（原文）:
> 商品が特定できていれば更新する、特定できない場合は人間が確認する

今回の保存依頼を根拠に、合意を以下へ転記する。引用以外は記録者の要約。PO発言の日時は会話に時刻がないため創作しない。新たなモデル呼出し・製品変更は実施していない。
