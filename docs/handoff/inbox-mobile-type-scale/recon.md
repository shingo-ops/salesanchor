# recon: 残りの見た目（文字の段・影・アイコン・ダークモード）の測定

調査日 2026-10-13 / ブランチ `release/inbox-mobile-type-scale`（`origin/main` 起点）

PO 指示: 並べた「次にできること」を順番に進める。その1番目＝**残りの見た目の測定**（文字の大きさ・太さの段／影／アイコンの太さ／ダークモード）。

## 0. 測り方と、その限界

- **当方の文字**: 読み上げツリーは**行の文字をまとめて1ノードにする**ため、要素ごとの画素測定ができない（実測: 行1つで1ノード・インク高さ110〜119px）。そこで**CSS とトークンの実値**で確定した（画素より正確）。
- **お手本の文字**: 要素ごとに `resource-id` があるため画素で測れる。ただし**インク高さは文字種に依存する下限値**（下に伸びる文字があると高くなる）。そこで ①**同じ文字種どうし**で比べ、②**線の太さ**（文字列の長さに影響されない指標）を併用した。
- 道具: 作業端末の /root/vl-benchmark-raw に置いた計測スクリプト2本（インク高さ・インク割合を出すもの／線の太さ＝暗い画素の連続長の中央値を 1〜8px に限って出すもの）。生データと同じくリポジトリには入れない。

## A. 文字の段（最大の差）

### A-1. お手本の実測（WhatsApp・ライト・チャット一覧）

| 役割 | 線の太さ（中央値） | インク高さ |

| 本文（`single_msg_tv`） | **4.0px（1.33dp）** | 41〜44px（下に伸びる文字を含むため高い） |
| 日付（`conversations_row_date`） | 4.0〜5.0px | 27〜28px |

### A-3. 差

| 指標 | お手本 | 当方 |
|---|---|---|
| 名前と本文の**大きさの比** | **1.32 倍** | **1.2 倍** |
| 名前と本文の**太さの差** | **1.5 倍（線幅）** | **差なし（どちらも400）** |

**太さの差が無いことが最大の差**。既読の行では名前と本文が同じ太さ・近い大きさで並ぶため平坦に見える。

## B. 影

| # | 事実 | 根拠 |
|---|---|---|
| B1 | 受信箱の `box-shadow` は**ドロップダウン・ボトムシート・パネルにのみ**使われ、一覧の行には使っていない | `frontend/src/pages/inbox/InboxPage.css` の該当行（`--shadow-xl` / `--shadow-dropdown` / `--shadow-lg`） |
| B2 | お手本も一覧に影を使っていない（区切り線も無い・検出0本） | `docs/specs/design-system/visual-language/benchmark/whatsapp-color-structure.md` ／ 画素測定 |

**影は差の原因ではない**（お手本と同じ作り）。本便では触らない。

## C. アイコンの太さ

| # | 事実 | 根拠 |
|---|---|---|
| C1 | アイコンは `weight` prop を**受け取るが無視**し、バリアントは import 元で固定する設計 | `frontend/src/constants/icons.tsx` の冒頭コメント |
| C2 | `strokeWidth` の指定箇所は無い | 同ファイルの grep 結果0件 |

**太さを変える手段が無い**（ライブラリ固定）。変えるならアイコン一式の差し替え＝ADR 級の判断になるため、本便の対象外。

## D. ダークモード

| # | 事実 | 根拠 |
|---|---|---|
| D1 | アプリは **OS の `prefers-color-scheme` を無視**し、アプリ設定（`users.theme`）を優先する | `frontend/src/index.css` の該当コメント ／ `frontend/src/contexts/ThemeContext.tsx` |
| D2 | 切替は `<html class="force-dark">` の付与で行う | `frontend/src/contexts/ThemeContext.tsx` |
| D3 | したがって**実機で測るには利用者の保存設定（DB）を書き換える必要がある** | D1・D2 から |

**判断**: DB を書き換えずに測るため、**画面検査の中で `force-dark` クラスを直接付けて測る**（CI 内のブラウザのみ・DB に一切触らない）。役割ごとの面積比は役割に色を割り当てている構造上モードで変わらないため、ダークで確かめるべきは**明暗差（コントラスト）**とした。
