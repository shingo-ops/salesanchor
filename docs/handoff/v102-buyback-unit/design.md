# design: 単位も状態も書かれていない件を買取価格で Sealed box / Case に決める（便BB）

参照: docs/handoff/v102-buyback-unit/recon.md、docs/handoff/v102-buyback-unit/card-BB.md、ADR-157、ADR-1007。

## 1. 目的（PO の言葉、2026-10-11）
- 「判断軸として買取価格を取得しているのでその相場感で判断することも出来る？」→ 比較優先度「買取価格>他社の販売価格>提供者固有の販売価格」→ 買取を最優先に自動で直す案に「y」
- 「単位も状態もない場合は sealed box,case,unsearched pack,searched pack のどれかである まず sealed boxとcaseの自動判定機能を作ってほしい、その後にpackを実装計画する」

## 2. 変更
| 場所 | 変更前 | 変更後 |
|---|---|---|
| v102 の保存（line_analysis_v102_svc._write_results） | 単位・状態の語が無い件は既定（箱系なら Sealed box/Box） | 単位・状態の語が無く商品が特定済みで価格がある件は、価格÷同じ商品の買取 BOX 中央値 r で、0.5≤r<2 → Sealed box/Box、r≥6 → Case/Case。今と違う時だけ書き換え、basis "BUYBACK:<状態> r=<比>"、unit_unknown・condition_unknown を外す |
| 買取の物差し | なし | 結び付き済み・BOX/BOX_SHRINK・last_seen_at が設定日数以内・店ごとの最新 price_s の中央値。1ジョブ1回の SQL、失敗は SAVEPOINT で飛ばす |
| 設定 | なし | tcg_distribution_settings に unit_buyback_box_min=0.5・box_max=2・case_min=6・max_age_days=7。無い・不正なら何もしない |
| 対象外 | | 単位や状態の語がある件、人が状態を決めた件、〆（excluded）の件、パック |

## 3. 受入条件
| 基準 | 検証方法 |

| B1 v102 現行全件で変わる件は全て原文で正しい（外れ0） | 置き換え試験＋原文判定（8行・当たり8） |

## 4. 代替案
- 他社の販売価格・同じ仕入元の価格を物差しにする: 他社は決まる件がわずか、同じ仕入元は誤りを引き継ぐので使わない。
- パックも決める: 確かめられたパックが3商品・11行で根拠が弱い → 次の便で計画。
- 値が同じ件も basis を書き換える: 〆の引き継ぎ・品質集計が読む文字が変わるので、違う時だけ書き換える。

## 5. リスクと対処
- 買取のつなぎ間違い（2.1%）→ 別セッションで修正。今回の判定には影響なし（recon）。
- 線引き 0.5/2/6 は正解表を見て置いた値 → 箱 0.82〜1.38・カートン 11.94〜で間が大きく空いており、2〜6 は決めない。
- 買取が古い → 設定日数以内だけ使う。

## 6. 戻し方
- 設定4 key を消す（data/rollback.sql）→ 判定しない。コードは PR を revert。書き換えた件は再解析で元に戻る。

## 外部・過去事例の参照と我々への応用
- 外部事例: 使わない（社内の仕入元価格と買取価格の照合で、比べられる公開の実測が無いため）。
- 過去事例: 便UP（#4137）で自分の解析結果を相場にする弱さが分かり、独立した物差し（買取）を使う。
