# AI アシスタント（秘書を Hermes Agent のまとめ役＋係へ）— 要件のすり合わせ記録

状態: 草案（PO とすり合わせ中）。ここに書いた案は PO 承認前。PO の決定は「PO 決定」欄に原文と日付で残す。

## 0. 始まり（PO の言葉・2026-11-24〜25）

- 「いまの秘書チャットをHermes Agentに差し替えて総合的なアシスタントとして育てていきたい」
- 「共通のmdにはエージェントとしての話し方とか私との接し方など基本的な全てに共通する項目を登録、スケジュール管理役にはスケジュール管理に関するmdを別途読ませる、請求書管理役には請求書管理に関するmdを別途読ませるなど、それぞれ専属のエージェントとして対応をさせる」
- 「どのボットでも付け替えが出来る構造にしてABテストが出来たり … どのAIがどの分野において強いのかが判断しながら採用する」
- 「1,まずアーキテクチャから始める、要件定義を行いあなたと私の認識を擦り合わせて最終的な実現したり部分の認識からすり合わせを行って、どう作るかを一緒に進めよう」

## 1. すり合わせの進め方（案）

1. 最終的に実現したい姿（誰が・どこで・何を頼み・AI が何をして・何を人が決めるか）
2. 係の一覧と順番
3. 守る線（AI が自分でしてよいこと／承認が要ること／してはいけないこと）
4. 成功の測り方（数字か○×）
5. 作りの案（置き場所・Hermes の部屋の分け方・頭の付け替え・今の秘書の資産の引き継ぎ）

## 2. 既に決まっていること・今ある資産（事実）

- 頭の付け替えの仕組み: ADR-1058（Accepted 2026-11-03）。仕事ごとに使う AI を DB の 1 か所で決める。
- 今の秘書: ADR-1056（Accepted 2026-11-01）。AI に会社のデータも道具も渡さず、文を決まった形に直すだけ。作成は利用者が「作る」を押したときにアプリが行う。
- 秘書に足しかけの案: ADR-1077 決まり帳（Proposed）・ADR-1078 予定のカルテ（Proposed）・ADR-1080 読み上げ（Proposed）・ADR-1082 声の入力（Proposed）・ADR-1087 声どうしの会話（Proposed・草案）。
- Hermes Agent の仕組み（公式説明書で確認・2026-11-24）: 部屋（プロファイル）ごとに人格の文書・手順書・覚え書き・会話が別。共通の文書は同じ仕事場に置けば全員が読む。まとめ役から係の部屋へ振る機能は公式の追加部品。部屋ごとに使う頭を変えられる。覚える前に人の許可を取る設定がある。

係の候補（案・2026-11-25 時点）: まとめ役（必ず置く）／予定係／請求書係／見積係／返信係／発送係／リード係
- 今の秘書がしている仕事: 予定と請求書の下書き（ADR-1056）
- 見積: アプリに見積の機能あり（backend/app/routers/quotes.py）
- 発送ラベル: アプリに作る機能なし（調査 2026-11-24）。発送通知の機能の有無は未確認
- PO の追加（2026-11-25）「請求書発行後の未払いの請求書があるときに通知して相手に催促するか？と聞いてくる係も」→ 請求書係の基準「未払いの催促」として案に入れる
  - 事実: 請求書は状態（発行済み issued／期限切れ overdue／入金済み paid）・支払期日 due_date・入金日 paid_at を持つ（backend/app/routers/invoices.py:153、:899）。PayPal の入金確認の口あり（同 :1106）
  - 事実: 見積から作る請求書は支払期日が空（同 :592 `"due_date": None`）
  - 未確認: 状態を「期限切れ」に変える仕組みの有無。支払期日が空の請求書の催促の基準（発行から何日か）

基準の一覧の 1 行に持たせる項目（案）: 名前／何を見るか／数字（例 4 時間）／どの係が案を作るか／急ぎか（夜中の扱い）／動かす・止める／記録する数字（当たった回数・そのまま「はい」・直して「はい」・無視）

事実（Q4b の根拠）:
- Meta の経路では、お客様の最後のメッセージの時刻を meta_messages から数えて出している（backend/app/routers/meta_inbox.py:952）。backend/app/services/messaging_window.py:68 はそれを受け取る引数。いまは Meta の 24 時間の返信期限の計算に使う。
- LINE・Discord・メールなどすべての経路で同じ時刻が取れるかは未確認。

PO の希望として記録（係の論点へ持ち越し）:
- 返信の文を AI が作る（返信係）。

設計への持ち越し（Q2 から）:
- SA の Discord 連携のサーバーにはお客様の問い合わせ部屋（チケット）もある（ADR-009・ADR-159）。アシスタントと話す部屋はしんごさん専用の非公開の部屋に限り、お客様の部屋では動かない作りにする。
