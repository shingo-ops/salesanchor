### P7 守りの最小（試した順）

1. `--read-only --cap-drop ALL --security-opt no-new-privileges:true --tmpfs /tmp --tmpfs /run` → 終了コード 126。ログ: `/run/s6/basedir/bin/init: Permission denied`。原因は権限ではなく、`/run` の tmpfs が `noexec` なこと。→ `--tmpfs /run:exec` に変えた（カードの形からの変更。権限は戻していない）。
2. 権限なし → 終了コード 2。ログ: `s6-applyuidgid: fatal: unable to set supplementary group list: Operation not permitted`・`chown: changing ownership of '/run/hermes-service': Operation not permitted`。→ `--cap-add SETGID`
3. `SETGID` → 終了コード 2。ログ: `chown: changing ownership of '/run/hermes-service': Operation not permitted`・`s6-applyuidgid: fatal: unable to setuid`。→ `--cap-add CHOWN`
4. `SETGID CHOWN` → 終了コード 2。ログ: `chmod: changing permissions of '/run/hermes-service': Operation not permitted`・`unable to setuid`。→ `--cap-add SETUID`
5. `SETGID CHOWN SETUID` → 起動はしたが `/health` が出ない。ログ: `chmod: changing permissions of '/run/hermes-service': Operation not permitted`。→ `--cap-add FOWNER`
6. `SETGID CHOWN SETUID FOWNER` → **Up・`/health` 200・3 部屋の `/v1/models` 200**。

立った形の全引数: `docker run -d --read-only --cap-drop ALL --cap-add SETGID --cap-add CHOWN --cap-add SETUID --cap-add FOWNER --security-opt no-new-privileges:true --tmpfs /tmp --tmpfs /run:exec --env-file default.env -v bin0-data:/opt/data -p 127.0.0.1:8642:8642 <完成品> gateway run`

|---|---|

| CAP_SETGID | `s6-applyuidgid: fatal: unable to set supplementary group list` |
