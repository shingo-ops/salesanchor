# 予定の設定の画面 要件（草案・PO 承認待ち）

PO の方針（2026-11-25）: 予定の画面に関わる設定だけをこの画面に集める。設定を変えるときはこの画面で完結させる（1か所）。

## 入れるもの
| 区分 | 項目 | だれが決める | 今 |
|---|---|---|---|
| Google 連携 | つないでいるか・つなぐ前の知らせ・つなぐ・外す（外すと許可を取り消し、取り込んだ予定は残す） | 会社の管理者 | つなぐボタンは予定の画面の上・外すボタンなし |
| 予定の種類 | 種類の一覧（足す・名前を変える・使わなくする）・種類の色（Google の24色）・共有の初期値（自分だけ／全員／チームを選ぶ） | 会社の管理者 | 7つで固定・色は札の色で固定・共有の初期値なし |
| 開いたときの形 | 最初の表示の形・週の始まり・だれの予定を出すか | 一人ずつ | 週・日曜・自分だけで固定 |
| 新しい予定の初期値 | 予定の長さ・Meet を自動で付けるか | 一人ずつ | 1時間・手で付ける |
| 人ごとの色 | 人の色 | 今のまま | 色を選ぶ欄が決まった部品ではない |

## 入れないもの
- 人ごとの「表示」「共有」の設定（今は保存だけされ、どこにも効いていない）→ 種類ごとの共有と「だれの予定を出すか」に置き換えて消す
- Google 予定の取り込み方（ADR-1057 で変えられる範囲が狭い）
- 種類ごとに使った時間を数える画面（別の作業）

## 受け入れの基準（KGI 案）
| 基準 | 確かめ方 |
|---|---|
| G1 予定に関わる設定を変える場所が、この画面1か所だけ | 予定の画面に設定を変えるボタン・欄が0個（歯車で開くだけ） |
| G2 Google を外すと、Google の連携一覧からこのアプリが消え、取り込んだ予定は残る | Google アカウントの「サードパーティ接続」で目視○×・予定の件数が外す前と同じ |
| G3 つなぐ前に、データの使い道の知らせが出る | 画面で○× |
| G4 種類を選ぶと、その種類の色と共有の初期値が自動で入る | 新しい予定で○× |
| G5 共有「チーム」の予定は、そのチームの人だけが見られる | チーム外の人で開いて見えないこと○× |
| G6 今ある予定の見え方は変わらない | 移す前後で、人ごとの見える予定の件数が同じ |
| G7 開いたときの形・週の始まり・予定の長さ・Meet が、設定どおりになる | 設定を変えて開き直して○× |
