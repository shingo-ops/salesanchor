# 声で会話の測り方（目標 V1〜V6・PO が本番で試す手順）

- 目標の正本: `docs/handoff/secretary-voice-input/kgi.md` §5（PO 承認 2026-11-24「1」）。この紙は手順だけを書く。合格ラインは kgi.md §5 のとおりで、ここでは変えない。
- 設計: `docs/handoff/secretary-voice-input/design.md` §15・§15-13
- 測る版: 本番に「画面が外れた後にマイクを開かない」直し（便 V2・`card-binV2.md`）が入った後。
- 結果の書き方: 各回の欄に ○ か × を書く。× のときは「何が起きたか」を一言で。Opus が結果をこの紙の §8 に写し、合否を出す。

## 1. 準備（1 回だけ）

（１）PC の Chrome で https://app.salesanchor.jp/ を開き、ログインする。
（２）右下の「秘書に頼む」のボタンを押して、秘書チャットの窓を開く。
（３）窓の上の「声で会話」の切り替えを入れる。初めてのときは、マイクを使ってよいかをブラウザが聞くので「許可」を押す。
（４）V1 だけは画面を音つきで録画する（Mac は `shift + command + 5` →「オプション」→ マイクを内蔵マイクにして録画）。

## 2. V1 話し終わってから 2 秒以内に自動で送られる（PC・10 回）

（１）「声で会話」を入れたまま、次の文を 1 回話して、黙って待つ:「明日の午後3時に打ち合わせ」
（２）話した文が、自分の吹き出しとして窓に出るのを待つ。ボタンは押さない。
（３）秘書の返事が読まれたら、窓を閉じて開き直し、「声で会話」を入れ直す（毎回同じ始まりにするため）。
（４）これを 10 回。
- 見るところ: ①吹き出しの文が話した文と同じか ②話し終わりから吹き出しが出るまで（録画を Opus が数える。録画のファイルの置き場所を Opus に伝えるだけでよい）
- 合格: 2 秒以内 9/10 以上・文が同じ 9/10 以上

## 3. V2 読み終わると自動でマイクが開く（PC・5 回）

（１）「声で会話」を入れて、「こんにちは」と話す。
（２）秘書が返事を読み終わったら、ボタンを押さずに次の文を話す:「今日の予定は」
（３）読み終わったら、もう 1 回話す:「明日の予定は」
（４）この 3 往復を 1 回と数え、5 回。毎回窓を閉じて開き直す。
- 見るところ: ①手で押さずに 3 往復続いたか ②秘書の声（読み上げた文）が、自分の吹き出しや入力欄に入ったことがあったか
- 合格: 続いたのが 4/5 以上・秘書の声が入ったのは 0 回

## 4. V3 予定は「はい」で作られ、「いいえ」で作られない（PC・各 5 回）

（１）「声で会話」を入れて、「明日の午前10時に試しの予定」と話す。
（２）秘書が「〜を入れますか」と読んだら、「はい」と答える。
（３）アプリの「予定」の画面を開き、明日の10時に「試しの予定」があるかを見る。見たら、その予定は消す。
（４）これを 5 回。次に（２）で「いいえ」と答える回を 5 回。「いいえ」の回は、予定の画面に何も増えていないかを見る。
- 合格: 「はい」で作られたのが 5/5・「いいえ」で作られたのは 0 回

## 5. V4 請求書は声では作られない（PC・5 回）

（１）「声で会話」を入れて、請求書を頼む（例:「〇〇社に請求書を作って」。〇〇はふだんの取引先の名前）。
（２）秘書が「請求書の下書きを出しました。画面で中身を確かめて、作るボタンを押してください。」と読んだら、「はい」と話す。
（３）アプリの請求書の一覧に、新しい請求書が増えていないかを見る。
（４）これを 5 回。作る画面のボタンは押さない。
- 合格: 声で作られたのは 0 回

## 6. V5 追加の費用が 0 円（Opus が測る・PO の作業なし）

- 読み上げの今月の字数: 本番の台帳 `public.llm_usage_events` の `purpose = 'secretary_tts'` の `billed_characters` を、日本時間の今月 1 日 0 時から足す（数え方は `backend/app/services/secretary_tts.py` の `read_month_total` と同じ）。Opus が本番の読むだけの鍵で数える。
- 新しく使う有料のサービスの数: 便 V（#5738）・便 V2 の差分に、新しい外部の呼び先が無いことを Opus が差分で数える。
- 合格: 90 万字以内・新しい有料のサービス 0 件

## 7. V6 スマホでもできる（PO の Android と iPhone・各 1 回）

（１）電話のブラウザ（Android は Chrome・iPhone は Safari）で https://app.salesanchor.jp/ を開く。
（２）V1・V2・V3（「はい」と「いいえ」を 1 回ずつ）・V4 を、それぞれ 1 回ずつ試す。
（３）iPhone で、読み終わった後にマイクが自動で開かないときは、マイクの印を 1 回押して続くかを見る。
- 合格: Android は全部○。iPhone は全部○、または「読み終わりに 1 回押すと続く」で○（その場合は、その型で決めてよいかを PO に聞く）。
- 気づいたら書く: iPhone で読み上げの声が小さい（耳に当てる側から出る）か。
