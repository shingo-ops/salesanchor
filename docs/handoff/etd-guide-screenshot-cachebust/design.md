## KGI

| # | 基準 | 検証方法 |
|---|------|---------|
| 1 | 1-6 サブステップで `step1-07-overview-v2.png` が表示される | ブラウザで ETD ガイド Step1 → 1-6 選択して画像確認 |
| 2 | 旧 URL `step1-07-overview.png` は参照されない | tsx に旧パスが残っていないことを grep 確認 |
| 3 | immutable キャッシュを持つブラウザでも新画像が表示される | 既存キャッシュがあるブラウザで確認 |

## 外部・過去事例の参照と我々への応用

キャッシュバスティングの標準手法: ファイル名にバージョン・コンテンツハッシュを付与して URL を変える。
`immutable` ディレクティブは「同一 URL のコンテンツは永久に変わらない」を前提としているため、
URL を変えることが唯一の確実な解決策。今後の運用ルール: スクショ更新時はファイル名のバージョンを上げる（v2→v3→...）。
