# Design: ETD ガイド Step1 「ステップ2へ進む」ボタン移動

## KGI

| # | 基準 | 検証方法 |
|---|------|---------|
| 1 | Step1（portal）の 1-6 コンテンツ直下に「ステップ2へ進む」ボタンが表示される | 画面で 1-6 タブ選択後にボタン存在確認 |
| 2 | 1-1〜1-5 選択時はボタンが表示されない | 各タブを選択してボタン非表示を確認 |
| 3 | ボタンクリックで Step2（apis）に遷移する | クリック後にステッパーが Step2 に進むことを確認 |
| 4 | Step1 のフッターナビゲーション（旧「次へ」）は非表示 | Step1 表示中にフッターにボタンがないことを確認 |
| 5 | Step2〜Step5 のフッターナビゲーション（「次へ」/「完了」）は維持 | 各ステップでフッターボタンが表示されることを確認 |
| 6 | 日本語「ステップ2へ進む」・英語「Proceed to Step 2」が正しく表示 | 言語切替で文言確認 |

## 参照

- recon: docs/handoff/etd-guide-step1-advance/recon.md

## 設計方針

`SubstepPane` に `onAdvance` / `advanceLabel` をオプション props として追加し、
`isLast` フラグが true の場合のみ substep-detail 末尾にボタンを表示する。

portal ステップ専用のフッターナビゲーションを `currentStep.key !== "portal"` 条件で非表示にすることで、
ボタンが重複しない設計とする。

## 変更前後

| 項目 | 変更前 | 変更後 |
|------|-------|-------|
| 「次へ」ボタン位置 | ページ下部フッター（全 portal 表示中常時表示） | 1-6 コンテンツ直下（1-6 選択時のみ表示） |
| ボタン文言 | 「次へ」(`common.next`) | 「ステップ2へ進む」(`fedexEtdGuideStep1AdvanceButton`) |
| portal フッター | 常時表示 | 非表示 |
| 他ステップのフッター | 表示 | 変更なし（表示維持） |

## 外部・過去事例の参照と我々への応用

該当なし。本変更は既存コンポーネント (`SubstepPane`) への最小限の props 追加であり、
外部ライブラリ・OSS・外部事例の参照は不要な小規模 UI 変更。

過去事例として、`docs/handoff/etd-guide-remove-back/` にて戻るボタン削除（#2583）を実施済み。
同一コンポーネントへの変更であり、実装パターンは既存コードを踏襲する。
