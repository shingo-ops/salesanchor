## 経緯（2026-09-05 実測）

- `/tmp/bench01.md` が 13GB、`/tmp/CARD-BENCH-RECON-01/report.md` が 32GB。合計 45GB。
- ディスクが 100% になり ENOSPC で作業が複数回停止した（`gh pr checks` / `df` すら実行不可）。
- 同日中に 2 回発生している（1 回目の掃除後、再び満杯になった）。
- worktree 掃除で回収したのは約 5GB。桁が違う。
- 原因: コマンド出力を無制限にファイルへ追記したこと。
- 生出力をファイルに逃がす運用自体は正しい（チャットの折りたたみで欠落するため）。
  サイズ制限と削除タイミングの取り決めが無かったのが問題。
