# design: GO 委任の範囲に「設計どおりの計画」を追加する

参照: recon.md（同じフォルダ）、ADR-1003（docs/adr/ADR-1003-go-delegation-to-opus.md）

## 目的
PO の 2026-10-15 の発言を委任の正式記録に残す。これで、次のセッションでも「設計どおりの計画は Opus が GO を出す。設計から外れたら PO に報連相する」を同じ前提で扱える。

## 変更前後
- 変更前：opus-delegation.md の委任の範囲は PR の GO だけ。無制限鍵での本番変更は、CLAUDE.md:30 により作業ごとに PO の GO が要る。
- 変更後：opus-delegation.md に「範囲の追加（2026-10-15：設計どおりの計画）」の節を足す。内容は次の4つ。
  - PO の原文
  - 範囲は、PO と決めた設計に収まる計画の PR の GO（ADR-1003 の範囲の中）。無制限鍵での本番変更は含めない。
  - 期限は無い（恒久）。
  - 設計から外れたら止めて PO に報連相する。既存の例外と、CLAUDE.md:38「不可逆操作は必ず PO 確認」の操作は、引き続き PO 本人の GO が要る。
- あわせて、変更履歴に1行を足す。

## 対象外
- CLAUDE.md と ADR-1003 の本文は変えない。この PR は ADR-1003 の範囲（PR のマージ前の GO）の中で、委任の期限と条件を正式記録に書くだけにする。
- 無制限鍵での本番変更（CLAUDE.md:30「作業ごとに PO の GO」）を委任に含めることは、この PR では扱わない。CLAUDE.md:57 は危険 PR の GO の手順で、:30 を指していない（審査 r1 B1）。PO の「仕様から逸脱していないGOは全て」が :30 まで含む意図かは記録が無く【未確認】。含める場合は、ADR-1003 の改訂か新しい ADR と、CLAUDE.md:30 の改訂を、ADR-1015 の A 区分の PR で行う。
