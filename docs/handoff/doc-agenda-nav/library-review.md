## 見る点ごとの結論

1. **要件 §8 の7項目**: 7つとも節がある（1→§3、2→§4、3→§5、4→§6、5→§7、6→§9、7→§8）。ただし 2 は重複を数えられない（指摘1・2）。4 は §14 の事実が入っていない（指摘6・7）。
2. **K1・K9 の見込み**: 段1 の K9 6.7k は要件 §3 の実測値そのもの。K1 の 194・185・163 は式で出ていて、足し算は合っている（60＋34＋23＋22＋9＋46＝194。リポジトリの CLAUDE.md 9・AGENTS.md 46 はこの枝の `wc -l` と一致）。創作の数値は §3-2 f の「約57」（指摘8）。式の無い単価が2つ（指摘9）。按分の元の値は古い（指摘9）。
3. **L2 の穴**: §14 は穴を自分で書いているが、本文には対処が無い。それに加えて、既知の重複1件も今の数え方では数えられない（指摘1）。直す決まりを今の2件に当てはめると、PO の最優先の決まりを消すことになる（指摘2）。
4. **字下げした @**: kgi.md:22 の定義には合う（公式 L102-112 も同じ）。しかし PO 承認の要る変更として分けられておらず、段2 に混ぜている（指摘4）。
5. **P3**: §2 の承認済みの基準を弱めている。文字どおりに満たす形が安くできる（指摘5）。
6. **H1**: 本文に入っていない。L4 の確かめ方の命令も §14 と合っていない（指摘6）。
7. **粒度**: 段ごとの戻し方・測り方・受入表はおおむね実行できる。直す所は、L2 の受入（指摘1）・台本の順番（指摘10）・K11 の命令（指摘14）・L4 の2つ目の点検（指摘13）。
8. **books の置き場**: 公式の読み込み規則とは食い違わない（公式を 2026-11-02 に curl で取得して確かめた）。注意2点は指摘12。
