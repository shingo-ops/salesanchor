## 1. 目的
毎回 AI が読む決まりの文書を「目録＋場面で開く本」の形に分ける。毎回読む量を減らし、同じ決まりを2か所に書かない。

| L1 | 毎回読む量 K9 ≤ ~~6.5k~~ **7.5k**（2026-11-05 に変更。下の注記）、行数 K1 ≤ 200 | `bash scripts/dev/doc-entry-weekly-check.sh` の K1= と K9= |

- `~/kb` の中の削除・移動は PO の明示承認が要る。`~/kb` の記録は PO が save.sh で行う。設計は台本までにする。

- 本番・製品コードは触らない。
- 最初の段で全部を移さない。1段ごとに K1・K9 を測る（変更は一度に1つ）。

4. L4 を壊さない手順（chat-format.md の後半の扱い）。
5. 「本が無い／開かれなかった／読み違えた」を数える仕組み（§6 の誤りの3分類を借りる）。
6. 段の分け方、各段の戻し方、受入条件の表 `|基準|検証方法|`。
