## 0. 使う順番

商品を1件調べるとき、次の順で当たると空振りが少ない。

1. 公式商品一覧で 商品名・発売日・価格・内容物 を確定する
2. エキスパンションマーク早見表で 型番 を確定する
3. Bulbapedia または TCG Republic で 英語名 を確定する
4. 販売サイトで 実際に使われている表記 を確認する

## 1. ポケモンカード

### 1-1. 公式商品一覧（最重要）

URL: https://www.pokemon-card.com/products/

取れるもの: 商品名（正式名称）、発売日、希望小売価格、内容物、取り扱い店舗。拡張パック・構築デッキ・その他商品が1ページに時系列で並ぶ。

取れないもの: エキスパンションマーク（型番）、英語名。

実測: 2026-09-05 に1回取得しただけで、既存マスタにもカタログにも無い商品を約35件発見した。プロモ入りBOX・ポケモンセンター限定セット・トレーナーカードコレクション・ジャンボカードコレクションなど、マーク早見表では拾えない領域がここに集約されている。

注意: デッキシールド・デッキケース・プレイマット・カードファイルなどのサプライ品が数百件混在する。カードが入っている商品だけを選ぶ必要がある。2026-09-04 の PO 判断により、サプライ品は商品マスタに登録しない。

未確認: 取得したページで 2019-12 から 2024-05 までは確認したが、2024-06 以降と 2019-11 以前が同じページに含まれるかは未確認。

### 1-2. エキスパンションマーク早見表

URL: https://tcg-hokan.com/pokemon-card-expansion-mark/

取れるもの: エキスパンションマーク（型番）、商品名、発売日。1996年の第1弾から現在まで、シリーズ別・区分別（パック / 構築デッキ / その他）に整理されている。

取れないもの: 英語名、価格、内容物。

注意: 更新が追いついていない期間がある。2026-09-05 時点で最終更新は 2026-01-22 であり、それ以降の商品（ニンジャスピナー M4、アビスアイ M5、ストームエメラルダ M6 など）は未掲載だった。新しい商品のマークは TCG Collector で補う。

注意: プロモ・限定BOX は網羅されていない。この領域は公式商品一覧を使う。

### 1-3. Bulbapedia

URL: https://bulbapedia.bulbagarden.net/

取れるもの: 英語名と日本語名の1対1対応。商品ページに「English name (Japanese: 日本語名)」の形で併記されている。関連商品（限定版・セット版）も同じページに載ることが多い。

実測: Vスタートデッキ9種、スターターセットV5種、スターターセットVMAX4種の英語名をここで確定した。トイザらス限定・セブン-イレブン限定など、マーク早見表に無い商品もここで見つかった。

取れないもの: 日本の希望小売価格、エキスパンションマーク（本文には無い。ただしコイン画像のファイル名にマークが含まれることがある）。

### 1-4. TCG Republic

URL: https://tcgrepublic.com/

取れるもの: マーク付きの英語商品名一覧。カテゴリのサイドバーに [SB] Sword & Shield Premium Trainer Box のような形で、マークと英語名が対で並ぶ。

実測: SB / SP1 / SP2 / SP3 / SP4 / SP5 / SP6 の英語名を1回の検索で確定した。他のどのサイトでも見つからなかったもの。

### 1-5. TCG Collector

URL: https://www.tcgcollector.com/sets/jp

取れるもの: 最新商品のマークと英語名。早見表が追いついていない期間を補える。

実測: MEE / MEZ / MEM（2026-07-31 発売）、M4 / M5 / M6 / MP1 をここで確定した。

### 1-6. 30周年特別サイト

URL: https://www.30th.pokemon-card.com/product/

取れるもの: 30周年記念商品（2026年）の正式名称・発売日・価格・内容物。

実測: 30th CELEBRATION カードセット9種の正式名称をここで確定した。

## 2. 判断の記録

### 2-1. 情報源が食い違ったとき

2026-09-04 の PO 判断により、英語名は販売サイトで多数派の表記を採る。海外バイヤーが実際に検索する名前を優先するため。

例: スターターセットex イーブイex は、Bulbapedia が ex Starter Set Eevee ex、販売サイト6件が MEGA Starter Set ex Eevee ex と表記していた。後者を採用した。

### 2-2. 確認できなかったとき

推測で埋めない。NULL のままにする。既存マスタでも英語名は 271件中 17件が NULL である（2026-09-04 実測）。

## 4. 他の作品について

ワンピース・遊戯王・ドラゴンボール・ヴァイスシュヴァルツ・ユニオンアリーナ・ガンダム・ロルカナについては、同等の情報源をまだ調べていない。ポケモンで確立した4段構え（公式一覧・型番表・英語名・販売表記）が他作品でも成立するかは未確認である。
