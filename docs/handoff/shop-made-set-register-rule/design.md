# design: 公式に無い組の登録（手順書の例外）

参照: [recon.md](./recon.md)／ADR-1020／docs/specs/product-master/registration-rules.md

## 目的
PO 2026-11-21「2」（選んだ選択肢の文:「指示を変えて、組の箱を登録する。「投稿が多い組は登録する」を手順書に書き足してから、今の準備のまま予行へ進みます。」）を手順書に転記し、次に登録する人と AI が同じ判断をできるようにする。

## 変更
- registration-rules.md §1 に C5: 公式に無い組は原則登録しない。投稿が多い組は PO 判断で登録する。候補表に「公式に無い組であること」「件数」「試算（単品の悪化件数）」を書く。
- §4 に U4: 「多い」の目安は未決。決まるまで1件ずつ PO に聞く。前例1件。
- §4 に U5: 公式に無い組の日本語名・商品区分の決め方は未決。決まるまで候補表で1件ずつ PO に聞く。

## 対象外
- コード・DB・本番。目安の数値（PO 未決のため書かない）。

## 代替案
- 目安の数値を AI が決めて書く → PO の言葉に無いので不採用（規則は PO の言葉だけを載せる・registration-rules.md:5）。

## 受入条件
| 基準 | 検証方法 |
|---|---|
| C5 が §1 にあり、出所に PO 2026-10-30 と 2026-11-21 の言葉がある | PR の diff を読む |
| U4 が §4 にあり「未決」と書いてある | PR の diff を読む |
| 書類の索引検査が通る | CI の check_doc_index |

## 外部・過去事例の参照と我々への応用
- 外部事例: 不要。社内の登録規則の文言を PO 判断どおりに直すだけで、外部の数値で裏付ける設計判断が無いため。
- 過去事例: 2026-10-30 公式にある組（白銀のランス＆漆黒のガイスト ポケモンセンター・ポケモンストアセット）は、候補表と過去投稿の試算を出してから登録した。今回の C5 も同じく「候補表＋件数＋試算」を PO 判断の材料にする。

## 維持の仕組み
- 目安が決まったら U4 を解決済みにし、C5 の「1件ずつ PO に聞く」を目安に置き換える。
- 登録時は master-register-rules-guard が手順書の全文を表示する（この変更も表示される）。
