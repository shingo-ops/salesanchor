## Search controls (`btn-secondary field-h-md`, 6 targets)

`field-size.css:8` defines `.field-h-md` as `min-height: var(--field-h-md, 36px); box-sizing: border-box`; the `Button` base also uses `box-sizing: border-box` and `min-height: var(--field-h-md)` (`Button.css:7,15`). Each target explicitly adds `field-h-md`, so `secondary/md` adopts the existing common Button appearance while retaining the intended medium minimum height. This is not a pixel-identical rendering claim. All six are native `type="submit"`; preserve `data-testid` where present. They have no disabled/loading state and make no write request.

## Required regression shape

1. Use real pages/components, real `Modal`, `Button`, `usePermissions`, and translation resources; mock only API/auth boundaries.
2. For 10 native forms assert exact method/URL/payload, existing native required guards, success/reset/read, failure/retry, and pending/repeat. Only the nine Modal native forms have X/Escape/focus contracts. MasterListEditor inline form has add/edit/cancel/trim-required and existing grid placement, with no X/Escape/focus-return expectation. Roles assignment is a separate click-only type=button/onClick action: verify missing target disabled, exact PUT, cancel/X/Escape reset and existing pending behavior; do not expect Enter submit. Count create/edit branches separately.
3. For five remote searches, parameterize click/Enter, trim/encoding, page reset, clear, exact GET query, and zero writes. For MasterListEditor local search, parameterize click/Enter/trim/clear with no additional API calls.
4. Assert target `type`, `variant`, `size`, retained `disabled`, `form`, `data-testid`, handlers and labels. Assert all per-file `outsideLegacy` entries from the audit remain byte-identical.


## Cancel handler versus the next opener (source clarification)

Cancel closes without the save-success reset in Orders/Role forms, but that does **not** mean a later new/edit opener preserves the draft. OrdersPage:47-55 initializes emptyForm and selector for new; useOrdersState.ts:289-301 repopulates the selected record for edit. RolesPage:253-268 initializes emptyRoleForm for new and the selected role for edit. Reopen assertions must reflect those existing opener operations. Post-cancel rejection preserves the error/closed state until the opener is used; tests must not invent draft restoration across a resetting opener. This clarifies the observed contract and does not change product behavior.
