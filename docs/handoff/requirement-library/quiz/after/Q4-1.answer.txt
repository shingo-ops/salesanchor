# 計画: 「40パックセット ¥24,000」を1パック600円で保存する

## 結論
実装に入る前に、PO（しんごさん）の判断が要ります。この変更は、既存の決定 ADR-1027 と逆になるためです。

- ADR-1027「まとめ売りは値段を割らずに保存する」は、PO が 2026-10-17 に指定した方針です（`docs/adr/ADR-1027-bundle-sale-reading.md:14-22`）。
- 指定の中身は「値段はまとめ1つの値段で割らない」「数量はまとめの数」です。
- 今回の依頼は、その反対（24,000÷40＝600円）です。
- AGENTS.md は「ADR と実装が食い違ったら ADR を優先し、コードを ADR に寄せる（逆はしない）」と定めています。
- ADR-1027 を変えられるのは PO だけです（ADR 起案は PO の担当）。
- ADR-1027 を置き換えずにコードだけ変えるのは、AGENTS.md の方針に反するため行いません。

## 確認すること
1. **ADR-1027 を置き換えてよいか。** 置き換える場合は、新しい ADR（ADR-1021 便2 の「1枚単価にそろえる」を一部復活させる内容）を起案します。
2. **数量をどうするか。** 「パック数×40」にするか、まとめの数（1）のままにするか。1パック600円で保存するなら、数量は 40 にするのが整合的です（推奨）。
3. **割り切れない値をどうするか。** 例えば ¥24,001÷40 を丸めるか、要確認（`bundle_unverified`）に回すか。推奨は、割り切れない行を要確認に回して勝手に丸めないことです。
4. **割る対象をどこまでにするか。** バルク系だけか、全区分か。推奨は、旧 ADR-1021 便2 と同じくバルク系だけにして、影響を小さくすることです。
5. **既存データを直すか。** 保存済みの `bundle_size` 行（2026-10-21 時点で 157 行）は旧値のままです。直すなら、再解析（`reanalyze_v102_job`）と ADR-1033 の同意票が必要です。

上の 2〜5 は、依頼の趣旨から私が置いた推奨案です。まだ確定していません。

## 実装手順（1 の GO が出た後）
1. `bash scripts/new-worktree.sh release/bundle-unit-price` で作業場所を作ります。作る前に `executor-preflight.sh` を実行します。
2. **ADR を直します。** 新しい ADR を起案し、ADR-1027 の What 3 と 7 を置き換えます。その後 `node scripts/generate-adr-index.js` で索引を更新します。
3. **まとめ売りの読み取り箇所を変えます。** 次の2か所です。
   - `backend/app/services/line_analysis_v102_svc.py` の `_reads_bundle` 周辺
   - `backend/app/services/v102_bundle_svc.py`
   - 変更内容は、まとめと決まった行（対象は確認 4 の結果で決まる）で、単価を値段÷N、数量を数量×N にすることです。
   - 割り切れない行は `bundle_unverified` で要確認にします。
4. **周辺の整合を取ります。** 次の3つです。
   - 商品名「N＋単位＋セット」の表示（配信 SQL の1か所）
   - 単価の確かめの相場チェック（`v102_unit_price_check_svc.py`）
   - 価格の引き継ぎ・買取単位の判定からの除外（ADR-1027 What 6）。除外を続けるか、換算後の単価で通すかを決めます。
5. **テストを更新します。** `backend/tests/test_v102_bundle.py`、`test_v102_bulk_price.py`、`test_v102_price_inherit_pg.py` などに、「40パックセット ¥24,000 → 単価600円・数量40」のケースを追加します。割り切れない行・値段なしの行・境界（N=2）のテストも足します。
6. **本番データへの当たりを確かめます。** `scripts/dev/bundle_replay.py` で本番の全行に当て直し、決まる・決まらない・当たらないの件数を PR 本文に書きます。
7. `migrations/` は変更不要の見込みです。ただし、これは調査エージェントの所見で、私は未確認です。再解析は PR とは別に、PO の同意を得てから行います。
