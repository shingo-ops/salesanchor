# ADR-096: 顧客マスタ／CRMデータモデル（顧客背骨・商談・会話ログ）（ADR-SA-02）

## Status
Accepted

## Date
2026-06-04（起案: Hikky-dev / PO: shingo-ops）

## Context（背景）

現行は「リード管理」1行にリード＋商談＋取引＋日報＋会話要約を詰め込み肥大化（61列）。常連客型なので「顧客」を永続の背骨にし、商談・注文・会話を正規化する必要がある。

---

## Decision（What / Why / Scope）

### 確定した設計

箱を次に分ける（各箱の項目は正本 §4・§11 が正）：

#### 1. 顧客マスタ（背骨①・永続）

永続に保持する顧客の属性情報。

| 属性カテゴリ | 項目 |
|---|---|
| 基本属性 | 顧客名/呼び方/国/顧客タイプ/流入経路/取扱タイトル/販売形態/想定規模 |
| 連絡先 | （チャネルIDは別箱→ADR-098） |
| 請求先（B） | 当面1件 |
| 配送先（D） | 住所帳 1:N（ADR-097/ADR-101） |
| 営業情報 | 営業担当・重視ポイント・面談希望 |

#### 2. 商談（SFA・フロー）

初成約までの一時プロセス。常連客型なので基本1回。

| カテゴリ | 項目 |
|---|---|
| 進捗 | 進捗/温度感/見込度/手応え |
| 活動 | 返信速度（API自動＋手動上書き可）/問い合わせ回数/次回アクション/メモ/課題/競合 |
| 終了 | 失注理由（**選択式必須**）/対象外理由（**選択式必須**） |
| 日報 | Good/More/反省/レポート（**商談にぶら下げる**） |

#### 3. 会話ログ（やり取り1件）

| 項目 |
|---|
| ログID/日時/送受信/発言者/原文/原文言語/翻訳文/商談解析 |

#### 4. 住所帳（配送先D）

1顧客 : N（住所帳）。請求先B は当面1件。

#### 5. 自動計算項目（手入力禁止）

| 項目 | 計算元 |
|---|---|
| 1回発注額/月間頻度/月間売上見込/初回・累計取引/LTV | 注文から集計 |
| 会話数/最終会話日時/会話要約 | 会話ログから集計 |

### 仕組み（意図）

顧客はチャネル・商談をまたいで1枚のカルテ。商談は「初成約まで」の一時プロセス（常連客型なので基本1回）。リード管理の肥大が解消。分析軸（流入経路・温度感等）が顧客/商談に正しく付く。

---

## 実装上の注意（誤実装防止）

- **信頼度カラムは廃止**（採用しない）。
- **返信速度＝API自動入力＋手動上書き可**（API送受信が完了しない場合に手動で補えるように両対応）。
- **失注理由・対象外理由は自由記述にしない**（選択式必須＝集計のため）。自由記述の詳細欄は選択式と**別に**追加してよい。
- 顧客実績・会話集計は**書き込み可能カラムにしない**（派生値。トリガ/ビュー/集計で算出）。
- 住所Dは1カラム上書きではなく**子テーブル（1:N）**で実装（→ADR-097/ADR-101）。
