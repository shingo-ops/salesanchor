# ADR-137: v_company_stats フィルタ定義統一（取引額 SSOT）

| 項目 | 内容 |
|------|------|
| ステータス | Accepted |
| 決定日 | 2026-06-12 |
| 決定者 | Shingo（PO）|
| 関連 | ADR-108（受信箱カルテ設計）/ ADR-095（SSOT 2本背骨） |

---

## What（何を決めたか）

`v_company_stats` ビューの請求書フィルタ条件を変更する。

| | 旧定義 | 新定義 |
|--|--------|--------|
| フィルタ | `status != 'cancelled'` | `paid_at IS NOT NULL AND voided_at IS NULL` |
| 意味 | キャンセル以外の全請求（下書き・発行済みを含む） | **実際に入金が確認された請求のみ** |

`paid_invoice_count`（支払済み請求件数）と `last_paid_at`（最終入金日）カラムを追加し、カルテ表示に必要な全値をビュー一本で賄えるようにする。

## Why（なぜ変えるか）

旧フィルタ（`status != 'cancelled'`）は「入金前の見積・発行済み請求も取引額に含める」設計であり、ADR-108 が定める「実際の取引額」の定義と乖離していた。

`paid_at IS NOT NULL AND voided_at IS NULL` は ADR-108 の公式定義（KPI 基準）に一致する。

## 数値定義の変化（平易な説明）

- **旧**: 「キャンセルしていない請求の合計」→ 入金前・交渉中の請求も取引額に計上される
- **新**: 「実際に入金が完了し、かつ無効化されていない請求の合計」→ 実入金ベースの取引額

この変更により、カルテに表示される取引額は「帳簿上の売上見込み」から「実入金額」へ切り替わる。
