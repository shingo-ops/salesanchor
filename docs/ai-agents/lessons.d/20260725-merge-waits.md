- PR本文の編集だけでなく、コメント投稿（gh pr comment）も pull_request の edited を発火させ、必須チェックが strict の ruleset では現HEADへの再採点が完了するまで「N of N required status checks are expected」でマージ拒否になる。gh pr checks --required が古い採点の緑を返している間に撃つと、この拒否を踏む。待機は「必須が全pass」だけでなく「現HEADのSHAに紐づく実行が登録済み(total>0)かつ全完了(pending=0)」も条件にする（2026-07-25 #3102 で expected 拒否を実測）。
- git ls-remote --heads origin '<branch>' は、枝が0件でも終了コード0（成功）で終わる。存在チェックを `|| echo "(0件)"` で書くと、削除成功時に echo が出ず出力が空になり、空を異常と読んで誤停止する。削除確認は「ls-remote の出力が空であること」で判定する（2026-07-25 本便で誤停止を実測）。
