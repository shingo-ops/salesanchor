# Discordリアクション テーマ起票セッションの教訓（5件）

同一セッションでカード9便を出し、うち4便に設計パートナー側の不備があった。
実装役のカード外実行は1件。以下はすべて本セッションの生出力で実測したものである。

## 1. 読み取り便の停止条件を、読み取り結果に影響しない状態に置かない（分類 6-2）

読み取り専用カードの停止条件に「git status --short が1行でも出力を出した場合」を入れ、
実装役が正しく停止した。しかし後続の手順はすべて git show <SHA>:path と
git grep <SHA> であり、Gitのオブジェクト保管庫から固定SHAの中身を読む操作である。
作業台に未コミットの変更や未追跡ファイルが何個あっても、読み取る中身は変わらない。
関係のない条件で停止させた設計不備である。

対策: 停止条件は「その条件が偽なら手順の結果が変わる」ものだけに限る。
固定SHAからの読み取り便では、作業台の状態を停止条件にしない。

## 2. 実装役の端末は長い出力を畳み、その状態でも「省略なし」と自己申告しうる（分類 6-3）

全文開示を指示した4ファイル（120行・83行・30行・33行）が、実装役の端末で
「… +47 lines (ctrl+o to expand)」の形に自動で畳まれ、設計パートナーに中身が
1行も届かなかった。それでも完了報告の末尾には「省略した出力はありません」と
書かれていた。実装役の手元では ctrl+o で展開できるため、実装役の主観では
省略していない。次便で同じ資料を頼んだところ、今度は報告の前半ごと落ちた。

三度目に、既知の行数から逆算して1コマンド18行以下に割り、各出力を
=== BLOCK_N_START <パス> <開始行>-<終了行> === と === BLOCK_N_END === で
囲ませたところ、全文が届いた。以後7便すべてで再発なし。

対策: 全文開示カードは、先に wc -l で行数を取り、そこから逆算して
1コマンド18行以下に割る。マーカー行で各ブロックを囲ませる。
検収は「省略なし」の自己申告ではなく、行範囲の明記で行う。
報告に「+N lines」「（省略）」「上記の通り」が在れば、内容にかかわらず未受領として扱う。

## 3. 実装役のまとめ表を file:line 引用の根拠に使わない（分類 6-3）

実装役が完了報告に、クラス名・イベント定義行番号・intent設定をまとめた
罫線表を添えてきた。内容は後の実測と一致していたが、表は生出力ではなく
実装役が作った二次資料である。recon.md の path:N 引用にそのまま使えば、
出所が「実装役の要約」になる。

対策: まとめ表は判断材料に使わない。カードで「まとめ表を作らない・生出力のみ」と
明記する。引用に使う値は、その値を出すために実行したコマンドの生出力から取る。

## 4. 逐語原本の輸送で アスタリスク と アンダースコア が装飾解釈で消える（分類 6-2）

executor-preamble.md の全文を取得したところ、本文中の docs/specs/**/ideal-state.md が
docs/specs//ideal-state.md と、アスタリスク2つが消えた形で届いた。
一方、同じセッションの別便で tail -n 1 だけを取った生出力では
docs/specs/**/ideal-state.md が保たれていた。同一ファイルの同一箇所であり、
消えた側が輸送崩れ（Markdown装飾解釈）と判定できた。

対策: 逐語原本を貼る前に、別経路の生出力（tail・grep 等）と記号を突き合わせる。
記号を含む文字列はバッククォートで囲んで輸送する（§5.5-1 の実例が本件）。
突き合わせずに貼った定型文は、写し崩れたまま実装役に届く。

## 5. 実行環境のOSを確認せずコマンドを書かない（分類 6-2）

不可視文字を可視化するため cat -A をカードに書いたが、実行環境は macOS で
cat -A は非対応だった。実装役は停止せず、自己判断で cat -v に置き換えて実行し、
その旨を報告に添えた。結果は無害だったが、常設ルールの「矛盾が出たら
自力回避せず停止」に反する。同時に、環境を確認せずコマンドを書いた
設計パートナー側の不備でもある。

なお本件は 20260902-data-durability.md の教訓5「カードに書かれた手段が失敗した場合に、
別の手段で同じ目的を達することを禁止する」と同型の再発である。
同教訓は対策として定型文への一文追加を提案していたが、
2026-09-04 時点の docs/ai-agents/executor-preamble.md（全30行・本セッションで実測）に
その一文は入っていない。既存対策が未反映のまま再発した。

対策: 環境差のあるコマンド（cat -A / sed -i / date のオプション等）は、
代替を併記するか、使わずに済む書き方を選ぶ。
executor-preamble.md への一文追加は別便で行う（本便のスコープ外）。
